# Content preserved in the unified monograph

The original 66-page proposal and 153-page monograph are integrated into a single 232-page, ten-chapter book. This map accounts for all 207 body units, including nested proposal inputs. Original page counts are measured from the frozen PDFs. The final typography remains the monograph’s 12-point A4 setting.

Each row identifies a frozen original and its destination. The printed page number is the number visible in the book; add nine to locate that page in a PDF viewer. The [machine-readable record](source-retention.json) stores source line boundaries, hashes, exact before/after edits, heading changes and added bridges. The [checker](../../../../scripts/check_unified_monograph.py) reconstructs the transformed body and compares it with the actual chapter; a retained flag alone is insufficient.

All 207 transformations match. All 33 original equation environments, 18 code listings, six figures, 119 labels and 76 cited references are retained. Tables remain inside the checked source units. The duplicate front matter is consolidated separately in the [front-matter map](front-matter-map.md). Added execution material has its own entry below. This record establishes inclusion, not independent acceptance of legal meaning or readability.
