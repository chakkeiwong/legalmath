# Critical review of the master program

23 September 2026. Author/executor review, not an independent legal opinion.

The revised program may proceed. Its acceptance conditions answer the user's
eight requests, but the following defects in the first execution design required
correction before treating its outputs as evidence.

* The earlier source-unit checker is deliberately byte sensitive. Teaching
  insertions and necessary corrections must have an explicit reversible edit
  record; disabling the checker would destroy the preservation evidence.
* Alphabetical file traversal is not reading order, particularly for the nested
  executed-workbench chapter. The inventory now traverses actual input locations
  and recognises optional short chapter titles. It records every label in a
  multi-equation display.
* MathDevMCP's advertised `--max-labels 0` did not examine every label: it selected
  30. A second execution with `--max-labels 100` selected all 37 baseline labels.
  A complete selection is still not a proof of the selected claims.
* A short exact quotation must support the particular manuscript claim. Merely
  finding the title or a matching keyword is not reading evidence. The archive
  manifest therefore starts with unchecked support and cannot promote itself.
* The present implementation includes E01–E09 scripted interpretation work.
  Describing the whole controller as future work is stale. Conversely, scripted
  correctness cannot support a claim about live-model legal accuracy.
* The applicable regulatory population matters. The SFC's generative-AI circular
  addresses licensed corporations and specified uses. Bank deployment requires
  an entity/activity-specific applicability analysis; an SFC reference alone
  cannot settle the position of every private bank.
* Mean diagrams per page can conceal long unexplained stretches. The validator
  reports each pair of consecutive body pages without a figure. A diagram's
  presence is only a location check; its explanatory value requires reading.
* Existing byte-preserving repetition is substantial in the RuleIR and assurance
  discussions. The instruction to inform before deleting applies. Retain these
  passages and improve their local explanation; no large deletion is authorised.

No baseline, test count, model review, source archive or successful document build
establishes regulatory robustness. Production suitability remains a separate
judgment requiring independent legal interpretation, operational validation and
the unresolved deployment controls. Missing human feedback does not stop the
requested provisional rewrite.

Execution red-team findings: a leaked table font setting reduced the manuscript
without deleting content; page count alone did not detect this readability loss.
The scope was repaired and body typography restored. The Stipula–KeY appendix
and pinned official example fail Java type checking; archived code presence
therefore cannot establish reproducibility. Source-reading evidence now records
the compiler diagnostic and the difference between historical paper status and
subsequent repository contents.

The final program also validates the identity and completeness of the retained
rendered-page, official-currentness, teaching-map and program-guard records. This
stage checks evidence bytes and explicit limitations; it does not turn those
records into legal, semantic or human-reader acceptance.

Final execution audit found a further material defect: regenerating the citation
binding could copy a source-level judgment onto a changed manuscript passage.
The binder and validator will therefore require a separately retained,
occurrence-specific review tied to the exact context, source and reading-record
digests. The executable program must never create that review. The smallest
adversarial diagnostic is to change one word or one source digest in memory and
verify rejection; unchanged records must still pass. A build or timeout failure
must also stop dependent stages and preserve a failure manifest, rather than
allow stale products to look newly reviewed. These changes preserve the original
baseline and do not change any scientific promotion criterion. The revised plan
passes this skeptical audit only with those controls and their diagnostics.
