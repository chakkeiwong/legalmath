# Next work from the round-14 findings

This is a successor specification, not a record of completed work. Activate it
only after the round-14 final report, regression result and post-execution
manifest verify. The accepted implementation and its limitations are described
in `docs/implementation/interpretation-round14/execution-result.md`.

The question is whether the retained source uncertainties can be narrowed while
preserving the useful decisions now demonstrated on circular 23EC52. The exact
comparator is the accepted round-14 reading set, source packet, compiled Java
and withheld development cases. More executable children, fewer differences,
more agreeing models or fewer open rows are explanatory counts. They are not
promotion criteria for the English interpretation.

The restored queue contains 231 pairs with executable original readings
(68 STR and 163 gifts) and one pair with an unencoded STR reading. At the
previous 12-pair fidelity batch size, the executable queue requires at least
20 first-pass requests. Preserve the unencoded pair as a distinct obligation.

## Interfaces that make the next program executable

Reuse `EvidenceJournal` for immutable attempts, `CircuitReader` for bounded
dispatch, and `Allowance` for the shared reservation ledger. Reuse the existing
source-fidelity request/validation functions rather than creating a second
label vocabulary. `explicit_resolution.py` is the child/parent contract;
`invariant.prepare` is the strict question/fact alignment boundary;
`invariant.decide` and `invariant_java` supply conditional aggregation.
`resolution_verify.py` demonstrates the installed cvc5 and Catala routes.

Before dispatch, the next fixed master must write `issue-inventory.json`,
`reference-lock.json`, `next-phase-plan.json` and a run manifest. Each phase
records exact arguments, input hashes, environment, commit, elapsed time,
reservation counts, result hashes and remaining obligations. `execute --from`
must verify all predecessors against current code and source bindings. The
repair path must preserve rejected attempts and change the input/request
identity explicitly; it must never edit an old response into a passing one.

Do not implement a new master by copying old absolute action-directory numbers.
Resolve accepted paths through the verified phase-results record. Immutable
attempt directories are evidence; the mutable summary alone is not authority.

## Budget, defaults and stopping rules

Read the remaining allowance at activation. The existing authorization is 500
total reservations and includes every failed preliminary round-14 call. The
initial next-increment ceiling should be `min(500, start + 30)`, with at most
20 first-pass calls for S1, four for targeted S2 proposals/reviews and six held
for structural repairs. This is a convenience budget to test first; calculate
the actual executable-pair count and prompt sizes before accepting it. If that
budget cannot cover the required work, retain an explicitly bounded pending
queue rather than shrinking the comparison universe or resetting the ledger.
S3/S4 deterministic acquisition and source inspection do not consume model
reservations unless the plan explicitly dispatches a model.

Preserve the first-transport-failure circuit breaker. Use at most three attempts
per phase and a fresh declared wall bound tied to the actual start. A source
concern or failed candidate blocks promotion and triggers its planned repair.
Corrupted evidence, an invalid harness, required unavailable authority or
exhausted resources stops only the work that depends on it. Independent
deterministic checks and honest documentation continue.

The 12-pair fidelity batch, 24-pair exclusion-challenge batch, exact
whole-basis-point interface, local-time assumption and
single model route are inherited convenience choices or scoped hypotheses.
Review each against this phase's question. Fractional exposure cases explicitly
challenge the old input precision; source classifications challenge the old
supplied-fact boundary. Do not transfer a successful de-minimis threshold test
to certificates, gifts, temporal duties or general case law without new evidence.

## Skeptical review of this successor

The largest newly observed risk is routing: the challenge restored relevance
in 232 of 272 pairs previously omitted. That finding is a new model judgment,
not proof that all 232 previous exclusions were wrong. It is sufficient to veto
reliance on those exclusions until reassessed. S1 therefore precedes further
claims of coverage. S2 preserves parents so narrow executable children cannot
create a false appearance of completion. S3 names the unavailable premise rather
than treating a successful download as resolution. S4 requires printed-page
evidence. S5 checks useful decisions with genuinely changed cases. S6 separates
engineering success from empirical legal assurance.

This ordering can reduce unresolved questions without a comprehensive external
legal consultancy engagement. It cannot manufacture authoritative premises or
an independent accuracy estimate. Targeted judgments are a possible source of
evaluation evidence; they are not a mandatory approval step for every rule.
Production bank integration remains deferred as previously requested.
