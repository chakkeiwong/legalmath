## Question, comparator and evidence contract

Can a common declared predicate interface let us compare source-derived
interpretation procedures without conflating a prose mismatch with a semantic
error? Can the bounded ensemble expose a seeded change while retaining genuine
uncertainty? This is a development diagnostic on the existing two-family,
four-case convenience set. It cannot estimate population English accuracy,
consultancy savings or which method is superior.

The old exact-prose scorer and monolithic arm are the engineering baselines to
repair. The revised live comparator ladder is one reader; two isolated readers;
two readers plus a missing-reading search; and that search plus source criticism
and one bounded reconsideration/audit. These are concrete new method profiles,
not new names for the unmodified legacy adapters. The same source, question,
declared facts, output meaning, time ceiling and twenty-four-call ceiling go to all
arms. A task has at most three attempts. The largest arm has eight tasks and fits
that ceiling. Keep successful tasks across interruption and count every failure.

The declared public interface consists of the question, input names and meanings,
types, qualifications and neutral predicate meaning. It contains no expression,
expected outcome, hidden snapshot or accepted answer. State explicitly that
this measures interpretation conditional on a supplied factual abstraction;
it does not assess automatic vocabulary discovery. The hidden reference retains
its own expression and cases. A versioned reference translation replaces the
misleading compliance tag with predicate satisfaction without changing the
declared Boolean function. Existing references remain unchanged.

Primary engineering criteria: reject source/interface drift; allow paraphrase
under the same declared question and facts; reject a changed question or fact
meaning; replay all retained candidates in Java and Python; retain every job and
failed dispatch; and report candidate-set coverage separately from final
acceptance, abstention, missing execution and excess alternatives.
