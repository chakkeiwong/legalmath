# BASF exact scalar occurrence repair

Question: can the unchanged frozen BASF construction expose its six legacy
scalar substitution kinds through exact, inspected source occurrences, without
inventing applicability or promoting incomplete legal answers?

## Baseline and skeptical plan audit

Baseline: branch `feature/prospectus-evidence-master`, commit
`03883b5f7d914a2678ac4f472e688c9fc1c60006` plus retained uncommitted integration
repairs. A1/attempt-008 is the protected construction comparator. Current BASF
consumer attempt-001 resolves three references, retains fifteen markers and
537 unresolved intervals, and returns UNKNOWN/UNKNOWN/PARTIAL in ASSISTED mode.
Do not rebuild historical programs or change their artifacts.

Audit verdict: PASS for the bounded engineering repair below. Code tracing
confirms that `as_assembly` drops exact replacement provenance when the old
admission supplies only page-text offsets. `construct` itself need not change.
One material design correction precedes execution: `"BASF"` is selected from
the base alternative `["BASF"]["BASF Finance"]`. It is not a quotation from
the final terms. Its raw source must be the selected base literal, with a
separate final-term issuer authority. Value copies must use their inspected
final-term raw occurrences. Neither a matching duplicate nor a deleted field
template establishes that relationship.

The optional admission will bind the full current graph and construction,
identify each exact legacy operation, and require complete, unique coverage
of all nonempty legacy substitutions when supplied. Each record distinguishes
VALUE_COPY from LITERAL_SELECTION. The selected literal must lie inside its
own replaced base alternative; its authority must bind the inspected issuer
on the same final-term page as the legacy issuer basis. Value evidence must
bind the same document, edition and page as its legacy basis and equal the
inserted text. Retain explicit development review records. Default requests
without an admission keep the visible unmapped behavior. No automatic search
or independent legal acceptance is introduced.

Review packets will retain exact anchor identities, original-page image
hashes, graph/construction identities and an explicit occurrence inventory.
The consumer must compare the unchanged construction with A1/008, demonstrate
every admitted replacement at its selected output use, and retain the full
remaining obligation inventory. Shared occurrence mapping can use existing
Text/Field copies: a selected literal is a Text copy from the base prospectus,
with separate selection authority metadata, never a Field copy of that
authority. Do not add a new generic quotation interpretation.

## Execution

1. Inspect final-term images 2-4 and base images containing the substitutions.
   Read the exact raw units and retain a reproducible unmapped baseline and a
   reviewed operation/occurrence inventory before filling the packet.
2. Add the optional scalar admission at the BASF assembly boundary and pass it
   through the existing construction request. Preserve `construct` output and
   existing raw-copy behavior. Keep authority distinct from copied text.
3. Exercise exact positive mapping and adversarial controls: stale edition,
   graph and construction, repeated/wrong occurrence or operation, missing
   binding, altered text, deleted-template misuse, foreign/absent selection
   authority, and false mapping of the authority as the selected literal.
4. Execute the real BASF consumer and the focused regression. Once these pass,
   run the existing successor/financial regression and the hash-locked installed
   fresh/relocated/restored application on the same reviewed request.
5. Update attribution evidence and residual obligations from actual results.
   Refresh newly stale closure phases only after auxiliary evidence is valid;
   retain PARTIAL and external acceptance NOT_ESTABLISHED. Update reset/result
   notes and the next substantive action. No commit or remote action is needed
   for this increment.
