# Deliver the definition profiles in the installed package

This is a same-task continuation dossier, pending the admitted source-application
trial and a reviewed authority revision. It creates no separate execution
authority and grants no new live calls or external permissions.

## Reproduced configuration gap

The production definition reader loads definition_scopes_spec.json.gz beside
its Python module. The application supplement also loads a compressed profile.
The package-data list in pyproject.toml contains
prospectus/successor/*.json but no matching pattern for .json.gz.
The files are available in the source checkout. That alone does not establish
that a wheel includes them or that an installed service can read them.
The configuration omission is a local delivery problem; it is not evidence that
an external package cannot support the prospectus task.

## Research intent and evidence contract

Question: do the exact reviewed source profiles and the ordinary answer survive
building and installing the package? The comparator is the completed finite
source-application trial, using its full products and answer. Build two wheels
from the same protected package tree: the current package configuration and a
configuration adding the compressed-profile pattern. Keep independent source
file hashes and the before/after configuration.

Primary pass criteria are a reproduced missing-data failure in the baseline
wheel, complete inclusion and byte identity of the required profiles in the
repaired wheel, isolated imports from the repaired install, and equality of the
complete ordinary answer with the retained trial. A changed input with valid
product hashes must still be refused at the expected consumer check.
Package counts, build success and runtime are explanatory only.

Promotion vetoes: baseline not actually reproduced; a missing/changed data file;
source-checkout imports masquerading as installed imports; differences in the
complete answer or an accepted forged meaning. Continuation vetoes: damaged
sealed inputs; unexplained source/method drift; missing actual results; or an
exhausted cumulative bound. Do not overwrite an old installed environment or
repair the old wheel in place. A failed candidate requires a reviewed changed
repair, never an unchanged retry.

Passing establishes delivery of the bounded supported behavior. It does not
establish general extraction recall, autonomous legal reasoning, portability,
the deferred CDM receiver trial, ACTUS behavior, or whole-build acceptance.
