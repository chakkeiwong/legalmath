## Proposed limits and decision rules

The contemplated live baseline is10 source reservations plus1 boundary probe.
At most2 further reservations could be allocated to one investigated repair:
for example, one two-call source retry or a trusted-context boundary retry.
They cannot fund both. This13-reservation proposal is not granted here. All13
native task admissions are already spent; a new name cannot create an allowance.
Keep task admissions, supervised process reservations and tool-internal
descendants in separate columns.

Use independently resumable stages, each<=120seconds with one-second tool
yields. Store complete objects once and references/deltas thereafter. Specify
an encoded storage cap before a live proposal is admitted; the retained stream
sizes and manifest logical sizes determine it, not an arbitrary small limit.
Snapshot sharing may use verified immutable inputs, but must not permit a race
probe to modify old blobs. Freeze the current method set before the canary and
check it after every stage. No installation, network or GPU dependency is
introduced by this design. Trusted native execution, if required by the host,
must use its actual permission mechanism and count failed launches.

Primary acceptance: every declared supported route supplies complete current
source/product/answer evidence, exact receipts and identities, plus real
boundary and prelaunch refusals. Missing bindings, unjustified source or answer
differences, unexpected calls, failed finalization or incomplete route coverage
veto the candidate. Corrupted sources or exhausted cumulative limits stop
execution. An expected candidate failure may trigger only the one reviewed
repair. Runtime and prior successful replay are explanatory only.

Even a pass establishes a finite supported runtime and source comparison. It
does not establish independent financial/legal interpretation, universal
dependency closure, portability, general table parsing, or prospectus completion.
The strongest alternative explanation remains shared source/interpretation
error on exposed examples. Independent readings and additional source families
remain separate requirements.
