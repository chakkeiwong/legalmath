## Evidence contract and defaults

| Diagnostic | Role and consequence |
| --- | --- |
| Exact source extents, all original occurrence identities, actual current consumers and whole-answer comparison | Primary scope acceptance criterion |
| Omitted/extended/duplicate source, false completeness, silently changed conclusions, inconsistent resealed dependencies | Promotion veto and repair trigger |
| Changed original evidence, invalid baseline, unsupported source edition, exceeded execution/storage bounds | Continuation veto for this package |
| Counts, timings, file sizes and test totals | Explanatory only |
| Unknown body meanings, office or actual event facts | Required explicit answer states; remain in their original substantive tasks |

The historical extents are a reviewed development baseline, not an inference
from line adjacency. The original images and raw anchors establish their source
provenance; controls test that current code cannot substitute another extent.
The current selected assembly is a hypothesis checked against the original raw
source maps. Explicit final-term premises bound applicability to this instrument;
no cross-instrument transfer is claimed. No stochastic ranking is involved.

Independent checking means comparing the production result with the immutable
original reviews and a separately implemented source/use enumerator. Reusing the
production check as its own oracle is insufficient. Conditional correctness of
the relation means every applicable reviewed governor points to every reviewed
selected occurrence, excluded branches point to none, and unknown meanings are
preserved. It does not prove that these development readings exhaust legal
interpretation or that underlying documents are authentic.
