Promotion vetoes: evidence loss, wrong-source/edition acceptance, unsupported
precedent, silent omission, incorrect Java comparison, false completed status,
or budget overrun. These trigger implementation repair, retained failed attempts,
new focused regression, refreshed plan and review before retry. Continuation
vetoes are corrupted provenance, unavailable required external inputs for a
dependent action, exhausted authorized budget or missing institution access for
deployment. Continue independent phases where these do not invalidate their work.

Defaults are finite engineering hypotheses: exact matching, capped catalogs and
context spans, bounded combinations/questions/examples, current stable Python/JDK,
and no default production scheduler. Their provenance is existing contract limits
or reviewed resource bounds; test exact limit and one-over cases, not just easy
examples. Source date is separate from retrieval date. Never assume today's Code
was in force on a circular's publication date. Full bytes survive excerpt selection.
