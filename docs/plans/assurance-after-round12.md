# Next discriminating work after the integrated assurance demonstration

This successor is driven by round-12 findings. It is not evidence that the
remaining requirements have been implemented or that legal review savings have
been measured. Bind its starting point to the final round-12 manifests before
execution. Bank integration remains deferred.

The immediate product question is whether a supported, useful decision can
survive independent source scrutiny with an intelligible and limited set of
remaining judgments. More candidate readings and more passing compiler tests
cannot answer that question by themselves.

## 1. Resolve specific authority and relevance questions

Start with the margin case's announced commencement, promised Code amendment and
gazettal, and later-notice limitation. Acquire the referenced official editions
and amendment material; retain exact bytes, publication/effective dates and the
source of any claimed priority. Freeze the additional source packet before
reinvestigation. Compare the operational-announcement and gazettal-dependent
readings on the same facts. The pass criterion is a source-supported disposition
of that particular issue or a clearly located residual requiring targeted
assessment. Retrieval success or a unanimous model answer is insufficient.

For eIP, investigate which product categories and submission types can be
classified directly from the retained official list and which need additional
definitions. Replace an opaque scope Boolean only when the new component
definitions are supported. Retain both old and new abstractions and a concrete
case where they differ. Do not equate facts merely because their names resemble
one another.

The STR example adds a control-identity requirement: channel compliance for one
submission, the need for an e-Cert under one method, and a report-level duty to
resubmit are different questions. Give each hypothesis an explicit question and
output meaning before forming claim/candidate comparisons. Preserve legitimate
partial controls for composition; do not label an e-Cert predicate wrong merely
because it does not itself decide a report's event history. Test the compound
obligation after typed composition as well as each individual control. The
round-12 broad selected slice exposes this risk but does not resolve it.

## 2. Make live output structure reliable without changing meaning

The raw abstraction records contain prose where executable expressions are
required. Add a separate syntax-lowering proposal over the retained meaning,
keeping the original proposal, assumptions and questions. Validate the grammar,
render the resulting rule back into controlled English, and require source
fidelity and conditional correspondence before considering it executable.
A failed lowering must preserve an unencoded reading. A syntax repair may not
discard an uncertainty, introduce a default fact value or change polarity merely
to compile. Measure recovery on the frozen invalid responses from round 12.

## 3. Resolve source structure on the actual PDF differences

Use the twelve located pages and retained crops. Build explicit row/column and
footnote-reference correspondences; compare them with rendered pages and retained
official text where available. Freeze a small source-structure reference set
before tuning alignment. Every resolution needs the exact region and evidence
that settle it. A repeated OCR answer does not create another independent route.
The acceptance set must include correct resolution of harmless wrapping and
retention or detection of lost negation, quantity, unit, header and exception.

## 4. Evaluate useful acceptance on independent evidence

Keep the author-mapped transfer cases as development demonstrations. Construct
additional reference cases from explicit official examples and targeted internal
compliance assessment of residual meanings. Reserve final sources by family and
edition; no reference answer reaches generators or repairs. Require useful
correct acceptance as well as mandatory abstention. Report unknown and unaligned
cases in the denominator. A second authorised model family can test empirical
joint failures; fresh Codex contexts alone do not supply that comparison.

Use equal-budget repeated-reader, abstraction-only and integrated-method arms.
Record severe unsafe acceptance, material omissions, correct useful acceptance,
avoidable abstention and actual correction effort. Freeze thresholds and handling
of source-family dependence before examining final results. Without adequate
independent reference support, report descriptive engineering outcomes only.

## 5. Extend the legal-semantic profile deliberately

Add language/edition links and provision-level bilingual comparisons while
retaining both official texts. An authenticated source or matching title does
not establish equal meaning. Priority relationships need sourced scope and dates;
cycles must remain unresolved. Connect a selected continuing-duty example to the
existing event engine and show how changed authority invalidates its dependent
evidence. General precedent interpretation remains a separate evaluated scope.

Each stage must retain the existing reserve-before-dispatch limits, exact input
binding, executed focused repair and refreshed next-stage plan. An unhandled
integrity failure stops dependent work; a failed legal candidate motivates the
specified evidence action. Promotion requires the declared substantive result,
not merely completion of the stage's command. Actual reviewer time is required
before making a cost-saving claim.
