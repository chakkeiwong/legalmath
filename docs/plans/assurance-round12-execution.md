Date: 25 September 2026. User instruction: create, thoroughly review, and execute

## Question and evidence contract

The engineering target is one persistent public-source investigation joining
source recovery, alternative factual models, breadth-first/UCT interpretation,
authority dependencies, independent execution checks, and actual Java delivery.
The interpretation target is conditional source support with explicit residual
uncertainty. The empirical target is useful acceptance on frozen examples and
an honest account of common errors. None of these substitutes for the others.

Baseline: main `9160ce72`, the protected uncommitted round-11 changes, the five
development circulars in `examples/multi-circular-2026`, and Catala branch
`5290bc53`. The original round-11 records are historical evidence, not current
validation after source changes. The author-created existing oracles are
development references, not independently adjudicated legal truth.

Primary engineering criteria: all required actions execute or retain explicit
uncertainty; changed upstream inputs invalidate dependent results; bounded
investigation survives interruption without refunding calls; real generated
Java agrees with declared semantics; the locked clear-case fixtures produce
useful answers and ambiguous fixtures remain unresolved. A named planted
material omission must not be silently accepted. Every stage's report binds
its code, inputs, execution and limits.

Promotion vetoes are source omission, unjustified fact equivalence, lost
alternative, unresolved material authority, inconsistent solvers or binary
outputs, missing mandatory route, unaccounted action, corrupted artifact or
accepted severe reference error. Explanatory diagnostics include proposal
counts, runtime, parser confidence, search scores and raw mutation percentages.
Continuation vetoes are an invalid harness, corrupt or missing required input,
unavailable authorised service after its bounded repair, or exhausted allowance.
An unresolved legal candidate is a repair trigger, not a reason to abandon
independent engineering phases.

No quantitative legal-accuracy, provider-independence, review-saving or universal
compiler-correctness claim is promoted without its own evidence. Human reviewer
time cannot be fabricated. A reference without independent source support keeps
its provenance limitation even if every engine reproduces it.
