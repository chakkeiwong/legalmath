## Question and evidence contract

Can a reusable bounded lexical mechanism propose exact quoted-label and literal
use intervals in selected language regions, with reversible whitespace maps,
without deciding whether a quotation declares anything or which scope governs?
The baseline is the current026 selected contract and source dossier, with025
ordinary answers protected for the later integration comparison. Numbered
reference discovery has no general term-discovery mechanism; a global
name-to-definition dictionary would silently apply local meanings elsewhere.

The primary criterion is exact agreement with independently authored naming
intervals and complete literal-use sets on the declared original excerpts and
constructed cases. The full selected contract has a separately authored quoted
label list; its other use counts are descriptive only. Quoted ordinary speech
must remain a proposal requiring review, never an admitted definition. The
candidate returns no governing scope or resolved legal binding. It does not
consume unquoted appointments, silently infer morphology or invent missing
definitions. Those known misses remain explicit source requirements.

Promotion vetoes: an omitted/invented interval in a declared complete case;
crossing an excluded-language/selection boundary; unsafe source-offset
normalization; binding a compound component as a standalone label; or inferred
meaning/scope. These trigger a named repair and preserve the failed candidate.
Continuation vetoes: corrupted frozen source/cases; changed reviewed method;
missing required evidence; exhausted reviewed bounds. An unsupported grammar or
legal ambiguity is a result for the next phase, not rejection of the direction.
Counts, timings and source hashes are explanatory. Passing proves only the
finite lexical behavior; it establishes no unrestricted linguistic recall,
legal correctness, answer integration, package limitation or build completion.

## Implemented-method review before admission027

The independent artifact now contains25 cases (four original excerpts) and47
manually read complete ASCII naming intervals in the full selected contract.
`cases-freeze.json` and its actual authoring receipt precede `candidate.py`.
This is temporal separation by the same agent, not a blind human annotation
study. The original excerpts have complete manually marked literal-use sets.
Full-contract use counts remain descriptive.

The implemented lexical candidate and staged trial live in
`reviews/definition-discovery-286/` and
`scripts/prospectus_definition_discovery_trial.py`. The API accepts an exact
text identity and a complete partition of selected and excluded language
regions. It retains raw spans and a character map for whitespace collapse.
Adjacent letters, numbers, combining marks, connector/dash punctuation,
apostrophes, soft hyphens and slashes prevent compound-component matches.
This boundary rule is an explicit bounded hypothesis, not general linguistic
segmentation. Overlapping multiword labels retain their literal alternatives.

The convenience safety limits are100000 source characters,256 regions and2048
quoted candidates; the current source has46365 characters and47 quoted labels.
These limits bound this trial rather than define product defaults. Actual
requests exceeding source/region limits must be refused. No candidate with
more than2048 quotations is evaluated or promoted by this package.
