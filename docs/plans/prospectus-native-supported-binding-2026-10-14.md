environment and absence of undeclared files, and preserve complete products on

## Research intent and evidence contract

Candidate: the existing optional sealed source route plus a named native-binding
evidence validator. Expected failures: incomplete explicit library/source
inventory, unsupported geometry propagation, incorrect receipt ancestry, and
overbroad acceptance based on a submitted PASS. Primary criterion: every matrix
cell and complete downstream comparison passes; validator independently derives
its verification from retained bytes and refuses each specified damaged case.

Promotion vetoes: lost or changed units/qualifiers/unknown geometry; changed
answers or clause/assembly semantics; unbound native fallback; incorrect
receipt/manifest/method identity; missing matrix cell or adverse evidence.
Continuation vetoes for dependent execution: corrupted original/source,
changed admitted plan, invalid shared comparator, failed prerequisite stage,
exceeded cumulative resource bounds or ambiguous previous process state.
A valid candidate failure blocks promotion and triggers one separately reviewed
changed repair or independent ready work; it does not reject the package as a
method. Counts and runtimes are explanatory only.

No independent legal correctness, general writing-family coverage, security
attestation, native cache reuse, statistical ranking, default change, cross-host
portability or whole-program completion follows from this test.

## Defaults, assumptions and pre-mortem

- The original por model, 300 dpi and five pages are exact comparator inputs,
  not tuned general defaults. First check the original hash and complete
  source-unit/image identities. Shared source-reading error remains possible.
- Reusing the 006 snapshot is a dependency hypothesis. Add only the exact new
  original source and a probe sentinel. Verify every retained blob and current
  worker/model identity before launch; do not infer universal dependency closure
  from the old trace. A failed closed lookup needs specific diagnosis.
- Text capacity remains explicit64MiB; OCR and verifier remain20MiB. These are
  inherited bounded capacities, not performance optima. Inspect actual byte
  sizes; overflow stops that cell without silently raising a cap.
- Each native child remains at most60seconds; each driver stage120seconds.
  Split source, construction and finish into separate commands. A timeout is a
  retained failure, never authority for duplicate execution.
- All execution is CPU-only with GPUs intentionally hidden before framework
  imports. The existing worktree interpreter and pinned module path are used.
  No installation, external source call, GPU probe or external message is needed.
- The read-boundary conclusion depends on the checked launch arguments and
  memfd seals under the declared Linux kernel trust. A self-produced hash is an
  integrity check, not authenticated remote attestation.

Pre-mortem: two identical answers could share a wrong interpretation, so their
agreement establishes engineering preservation only. A historical baseline
could be stale, so current method identities and a fresh default 2009 product
are required. A namespace probe alone cannot establish source integration, so
the actual P1–P5 consumers are mandatory. A generic PASS validator could hide
missing cases, so explicit matrix denominators and tamper tests are mandatory.

Skeptical audit: PASS for this bounded engineering package. It adds a genuinely
different original geometry-adverse source, preserves all original task scope,
and specifies separate product and evidence-integrity checks. It neither
requires independent readers for a deterministic file-binding test nor treats
that test as independent legal acceptance.
