## Evidence and implementation

Add a top-level archive_observations input, interpreted outside the source graph
so archive metadata cannot silently change visibility or original document dates.
P2 validates it using the request bundle and original document bytes. The final
consumer verifies its current bound evidence even during frozen consumption and
exposes a separately named source_archive_observations answer. Each report can
carry only observations for its exact document/edition. Existing external-fact
unknowns and report-use availability remain unchanged.

Each supplied capture binds the document/hash, exact original URL, capture_at,
retrieved_at, retained archive content, HTTP headers and exact index record within
a retained JSON response. Validate all file hashes inside the declared root;
compare complete original and archived PDF bytes; require successful PDF index
and response; match the record's timestamp, replay URL and original URL to the
Memento date and Link originals. Require the replay to be the supported HTTPS
Arquivo original-file URL for that timestamp and original URL. Hash agreement
between a summary and itself is insufficient. Last-Modified and PDF creation
metadata are not date authorities. Index compressed contentLength is not the
decompressed PDF length; validate the actual response Content-Length when present.

Retrieval time is supplied evidence provenance, checked against the retained HTTP
Date and capture date. Hash integrity cannot authenticate those headers or the
reviewer; state the archive's recorded observation conditionally. No credentials,
network, external messages or new acquisition are required.

Adverse checks: changed original/content/index/header bytes; hash-updated wrong
content; HTML at a PDF URL; wrong issuer URL; wrong capture date; ambiguous duplicate
headers/records; missing Memento; inconsistent or naive retrieval time; future
knowledge; path escape; unknown profile; duplicate capture identity; changed
evidence after P2; and a resealed forged P2 observation. Positive boundary tests
include exact query instant and matching source-specific report attachment.

## Skeptical audit and defaults

PASS with the knowledge-time baseline correction and a separately named observation.
One archive is a finite supported interface, not evidence that all archives share
this schema. A source URL is not issuer identity proof; exact bytes are the binding
criterion. The selected index row and HTTP headers are supplied development
evidence, not independent legal adjudication. Treating a 2015 capture as 2011
availability is an explicit promotion veto. Source/method corruption, mismatched
edition or changed matched debt/report facts invalidate the run. Counts/runtime
are explanatory only. Candidate failure triggers one bounded repair, not a new
task or an admission reset.

Pre-mortem: a later replacement edition could have the same present URL but
different earlier contents. Exact equality proves only what this archive record
contains at its recorded date. Even correct temporal arithmetic cannot establish
original publication or authenticity. The weakest evidence is trust in the
retained metadata; keep that qualification in the result.
