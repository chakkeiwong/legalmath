## Evidence contract

The primary criterion is a separately specified graph oracle, exact original
source and complete-target comparison, and actual ordinary/installed consumer
equality. The source review must precede the candidate. Freeze complete small
graph expectations before implementing the graph mechanism. Include self scope,
two-node scope/dependency cycles, true dependency cycles, missing targets,
unresolved scope links, disconnected cycles, duplicate identities, invalid
classifications and edge/root permutations. Retain a mixed cycle in which a
scope link participates; it remains visible in the source graph.

Use two graphs explicitly. The source graph contains every edge. Its reachable
nodes and missing/unresolved reference checks are unchanged. The conservative
dependency graph retains every unclassified or substantive edge and omits only
edges in the explicitly reviewed scope list. It tests that second graph on all
vertices reachable in the source graph, including vertices reached only through
a scope edge. Otherwise a scope link could hide a real cycle further downstream.
Cycles in that second graph remain unresolved. The output states the source reading and shows both graphs' cycle
components. It does not label all remaining edges proven logical dependencies.

For a finite graph, iterative traversal starting at the roots adds only endpoints
of edges from already reached vertices. Induction on path length shows that it
finds every reachable vertex; induction on additions shows that each discovered
vertex has a path from a root. Removing scope edges only for the second traversal
cannot alter the first graph. Two reachable vertices are in the same strongly
connected component exactly when each is reachable from the other; a singleton
is cyclic only when it has a self edge. These statements establish the graph
calculation given its edge classifications. They do not prove a natural-language
classification or solve recursive legal rules. A separate oracle uses repeated
reachability, while the candidate uses an iterative component algorithm.

Promotion vetoes: omitted original edge/target, a missing or unresolved reference
made resolved, an unreviewed edge suppressed, an isolated cycle treated as
reachable, a scope annotation treated as proof of a legal event, or any lost
prior answer field. Corrupt source pins, frozen drift and exhausted reviewed
resources veto continuation of this trial. Counts and runtime are explanatory.
Internal source review is development evidence; it is not unseen-document
accuracy, historical-law applicability, general legal truth or full acceptance
of the original task.
