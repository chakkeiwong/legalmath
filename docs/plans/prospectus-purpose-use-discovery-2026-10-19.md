## Method and assumption audit

Use the reviewed unquoted declaration recognizer, then identify its
PURPOSE_CONDITIONED_AMOUNT declarations. For the supported two-word form, derive
a family from a lowercase German adjective with an explicit ending and an exact
noun. Match the adjective stem plus e/en/er/es/em and the same noun, preserving
case and whitespace in raw quotations. These endings are a finite syntactic
hypothesis, not a general German morphological analysis. Compound components,
substring matches, unsupported term structures and blank-paragraph crossings
must not become supported occurrences. Missing or unsupported cases remain
explicit limitations. No vocabulary or record IDs enter the recognizer.

Resolve each declaration's printed section/paragraph address against the retained
source-bound index. A destination is usable only if exactly one indexed node has
that section and path; zero or multiple nodes remain unresolved. Preserve optional
printed brackets. Never synthesize an unindexed paragraph10(a) from an inline
label. Containment supports only a proposed printed-purpose connection. The
report must keep legal meaning and automatic interpretation unadmitted.

Classify exact declaration-term spans separately. A term immediately after a
printed paragraph label and followed by a full stop is a title candidate, subject
to review; do not inherit the whole source line's OPERATIVE role as the title's
role. Other occurrences are use candidates. For each, retain all compatible
declarations and record which unique printed-purpose destinations contain it.
Zero matches stays unresolved, and multiple matches stays ambiguous. A
declaration's own name identifies itself rather than borrowing a neighboring
purpose. Do not infer global precedence from text order or choose the first
declaration with the same name.

Default audit: the previous finite source readings are reviewed baselines. The
adjective endings, exact noun matching and title syntax are bounded hypotheses;
renamed terms, same-stem distractors, punctuation, case, line breaks, compounds,
blank paragraphs and missing/duplicate destinations provide early diagnostics.
The existing source projection and printed-address index are checked inputs.
Their prior tests do not prove the new occurrence-to-purpose connection. Use
CPU-only local execution; no external package or live call is needed.

Skeptical audit PASS for this bounded addition: a supplied term list would test
lookup rather than discovery; reusing the old binding matrix as generated
expectations would be circular; substring containment alone would silently
assign the broad reference or title. Independent source intervals, purpose
addresses, explicit ambiguous states and complete answer comparisons distinguish
these failures. Freeze source expectations before creating/evaluating the new
recognizer. Review implementation before admission.
