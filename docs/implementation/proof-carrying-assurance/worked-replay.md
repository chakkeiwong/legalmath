# What the executed 23EC46 replay actually found

This run uses all five retained proposals and the criticism proposal from
round 3, A7 attempt 08. It does not claim that a fresh model independently
rediscovered those readings. Source extraction and packet anchoring are rerun;
the circular's referenced authority text is not silently supplied from memory.

The program visits every retained candidate before comparing pairs. Two pairs
have exactly matching fact definitions and explicitly common output meanings.
Eight other pairs do not have a reviewed correspondence and remain
NOT_COMPARABLE. No candidate is removed by majority vote or a search score.

The first comparable pair asks whether an operational product connection is
necessary, or whether product-directed presentation can also satisfy the
connection condition. The SMT witness sets distributor/client scope and gift
classification true, fee-discount classification false, operational connection
false, and promotional presentation true. Python and both candidates' generated
Java return TRUE for the broader condition and FALSE for the operational-only
condition. The statement being checked is that the two encodings differ on
this declared input. It does not decide which reading the source supports.

The second pair concerns whether product-type linkage alone can suffice when
the separate promotional-connection fact is unknown. The witness sets the
actor/offer scope, gift and product-type-link facts true, fee-discount false,
and promotional connection unknown. One encoding returns UNKNOWN and the
other TRUE. Python and Java reproduce those same results. This example shows
why testing only fully known true/false facts would miss a consequential
behavioral distinction.

For each of the five encodings, both the direct Java and pinned Catala routes
compile and execute 24 declared cases, giving 120 finite comparisons per
backend. The dossier preserves the cases, build manifests, JAR hashes,
verification reports and detailed Python/runtime results. Both backends share

evidence rather than independent interpretation of English.

The argument engine reevaluates the retained typed criticism proposal and keeps
15 open questions. These include interpretation assumptions, source priorities,
missing FAQ evidence, component classification and actual offer facts. The
dossier's three completed obligations are type checking, finite Java replay
and finite Catala replay. Fresh generation and a general translation-proof

unresolved methods/questions, these produce 31 recorded blocking reasons.

The resulting BLOCKED_UNRESOLVED dossier is useful: it supplies executable
alternatives, exact separating facts and focused questions for further source

authority. The assessment clock is a declared replay convenience, not an
established legal effective date; see `assessment-time-assumption.md`.
