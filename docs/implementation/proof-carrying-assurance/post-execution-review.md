## What was implemented

A strict dossier binds the original manifest, retained source bytes, all proposed
readings, criticism, RuleIR, actual compiler outputs, finite execution cases,
search results, uncertainties and shared dependencies. The command-line interface
can consume another retained investigation without embedding a circular number
or its legal predicate in the adapter. Unsupported language preserves an
extension question and emits no substituted rule.

The execution adapter reextracts sources and checks anchors, reevaluates the
existing argument profile, visits all candidates before comparing pairs, and
actually builds and executes direct Java and pinned Catala programs. The
verifier reconstructs the target from the retained manifest and checks source,
argument, type, Python and recorded runtime evidence. It also checks that the
reader-facing disagreement summary, critical questions, objections and obligation
propositions preserve the meaning and limits of those results.

The master audits exact command vectors, stores failed and interrupted attempts,
archives declared input bytes, rejects stale inputs or outputs, executes focused
repair checks, refreshes its successor from verified predecessors, and requires
complete no-skip JUnit reports. A wrong-target mutation/rejection/restoration
exercise runs before full regression. Its final report cannot grant legal or
release authority.
