# Skeptical pre-execution review

11 October 2026. Executor self-review. PASS for the finite local program and
resource design; live dispatch remains conditional on its concrete method and
original authority. This review does not independently assess legal correctness.

The proposed graph repairs the demonstrated failure: a consumed local package
returned to a broad task name and ended the session although independent work
remained. The user's current instruction explicitly authorizes a reviewed change
to that work-selection policy. No fresh user approval is required merely to
review a next phase or edit local files.

The initial idea of a command-only run loop was insufficient: it could terminate
while legal analysis and implementation were still ready. The accepted design
includes agent work explicitly and refuses a complete/settled verdict while that
work or a declared recovery is runnable. A second flaw would have made every
task depend on the source-repair branch. The source contracts and resource design
have no such dependency; response qualification needs its own method/input
review, and full product evaluation alone joins the required branches.

Wrong baseline: capture dirty source hashes, retain nine detours and thirteen
charged calls. Proxy criteria: scheduler tests establish execution behavior only;
legal arguments and real answer effects have separate criteria. Stop conditions:
finite per-node attempts and the original overall clock, not an artificial stop
after every package. Unfair comparisons: matched answers must use the same source,
questions and method; a synthetic test cannot replace them. Hidden assumptions:
full matrix affordability, future populations, output capacity and model latency
remain hypotheses with an early resource screen. Environment mismatch: CPU-only
tests use the existing venv; live host permissions are requested only for the
concrete admitted command. Artifact relevance: each graph node has a named output
and an acceptance check, including failures and conditional legal conclusions.

Global versus branch vetoes require special review: a changed global grant or
corrupted graph invalidates authority; a failed local output invalidates only its
descendants. Expected negative qualification activates its named recovery and
does not cancel P14 or Gatecoin work. Recovery success must be an explicit
alternative prerequisite, not an instruction to erase the failed first attempt.

No plan guarantees all legal ambiguities can be resolved. Completion means all
admitted task outputs are delivered and evaluated, while original legal questions
and tool acceptance remain open wherever evidence is insufficient. A blocked
matched run must carry its exact missing prerequisite and not silently mark the
mission complete. Post-implementation adversarial tests and actual multi-branch
execution are required before claiming the start/stop pattern repaired.
