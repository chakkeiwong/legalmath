## Rejected decisions

The 25 decisions contain 43 issue occurrences. Fifteen rationales challenge the
necessity of a dependency for the answer actually written. Nine identify defects
in the answer's description of the available evidence. One has a REJECT label
but begins its reason with UNRESOLVED. Fourteen also contain an identifiable
mismatch between the assigned dependency and the subject discussed in the reason.
For example, staffing reasoning appears against paragraph-14/footnote-5 and
request-trigger assignments. A valid response schema did not prove that these
historical reasons were attached to the intended targets.

The remedy ledger records every issue separately and includes its actual
assignment. Issue warrants distinguish a criticism of an unnecessary dependency
from a supported defect in the answer. Neither the original REJECT label nor an
UNWARRANTED issue automatically changes the assignment's acceptance decision.
The same historical ambiguity can affect favorable decisions; preserving them
is an execution-reuse rule, not proof of semantic assignment correctness. A
corrected answer requires the complete fresh review with explicit correspondence.
