## Scope and root causes

The trace followed the selected public path through `legal_product_completion`,
`CompleteInvestigation`, `bounded_context`, `bounded_product`, reference transport,
the bounded provider, installed tool adapters, answer/effect validation, campaign
scheduling and mission admission. Retained requests, failed responses, native
controls, original source documents and the execution register were compared
with those implementations. Historical full-context programs were inspected as
evidence and comparators, not substituted for this route. This is a detailed
audit of the integration path; it is not proof that unrelated code or every
historical implementation is defect-free.

Three distinct problems explain the stalled integration. First, software
boundaries could lose or misattribute evidence even when a tool executed.
Second, the live route has not reliably completed the bounded investigation:
timeouts, upstream errors and expanded-response limits prevent qualification.
Third, formal engines operate on the expressions and graphs supplied to them.
Their correct execution cannot establish missing legal warrants, discover an
omitted authority by itself, or demonstrate an effect on an answer that was
never completed. More tool invocations do not resolve those third-stage duties.
