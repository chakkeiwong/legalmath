## What changed and what actually passed

The old live class guard refused the qualified ContextProvider even with a valid
underlying grant. The refusal was reproduced using blocked transport, before
repair, without contacting a service. The new verifier unwraps only known exact
ContextProvider wrappers and checks the original underlying provider, allowance,
route, qualified context, wrapper route and retained qualification evidence.
It verifies without reserving; the actual provider reserves once. Altered routes,
contexts, allowances, evidence, underlying objects and live flags refuse before
dispatch. These are process controls, not a host-security certification. The
unused single-reader route remains outside this qualified composition.

The whole-dossier consumer now shares exact content while retaining independent
contextual occurrences, stable identities and home accounts. Every retained row
and field reconstructs exactly. Inclusive account ranges expand before validation
and cannot conceal a missing, duplicate or foreign occurrence. All known explicit
interactions and reviewer-nominated dependencies enter an obligatory interaction
review before synthesis. Semantic dependencies absent from the supplied structure
still need substantive review; identifier coverage cannot establish understanding.
