## Repairs and their demonstrated limits

`source_context.py` defines an explicit qualified input and a parallel ordered
identity over raw source bytes, root/retained roles and selections. The existing
raw-source observation identity is unchanged. CompleteInvestigation's outer
revision, IntegratedInvestigation's interpretation action and Assurance's request
identity now bind that context. Selection-only and qualification-only controls
produce new investigations; identical inputs replay. Qualification evidence is
checked before cached response reuse and direct dispatch.

The qualification enters before request compaction, source-reference encoding,
size checking and provider caching. Both inventory readers, inventory repair,
generation, question assignment, fidelity/criticism, scoped requests and challenge
continuation retain it in the tested routes. Full and piece packets are checked
against original/compact unit hashes. The compact representation's separate
document-locator table is also bound; an altered or missing table is rejected.
Challenge qualification is bound separately from the configured provider
identities, so adding it does not falsely change the retained provider method.
Direct challenge calls check qualification evidence between dispatches.

These controls preserve supplied provenance. They do not authenticate official
sources, resolve applicable editions or turn inherited `normative=True` into a
reviewed legal classification. The prepared qualifications explicitly preserve
local reconstruction, historical UT selection/normalization, applicability
uncertainty, Appendix extraction disagreement and unsupported visual content,
and the distinction between page metadata and operative law.

The optional `dossier_answer.py` consumer archives the whole evidence tree,
including readings with null formalization, claims, criticism, judgments,
concerns, tool inputs/limits and unknown categories. Atomic substantive rows
remain whole. Exact duplicates may share contents, but every occurrence, path
and ancestor/role context is retained. Definition dependencies are drawn from
both row contents and occurrence context; nested argument definitions resolve
to their whole containing record. Orphaned claim/reading judgments are refused.

Bounded review groups feed a mandatory interaction review and complete-answer
synthesis. Each dispatch screens actual compact input size; review outputs are
capped at 4,000 bytes and interaction output at 8,000. Aggregate overflow stops,
without pruning, recursion or automatic retry. Final input retains every
generated reading and source qualification. The final schema retains tool
accounts, original questions and unresolved dependencies. None of these
engineering checks establishes faithful reduction, entailment or genuine
consideration of a tool result. Deliberately legally empty responses pass the
structural contract and are retained as a negative example.
