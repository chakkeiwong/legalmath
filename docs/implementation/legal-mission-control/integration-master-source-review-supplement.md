Primary source criterion: every conclusion names the inspected passage and
preserves the actual actor, instrument, conditions and procedural context.
Conflicting source text, absent original support, uncertain edition or an
unverified locator veto the corresponding stronger conclusion. Page counts,
conversion success, lexical match rates and service token counts are explanatory
only. A bounded search with no resolving authority leaves the issue unresolved
within that search; it does not establish impossibility or exhaust current law.

The current handbook edition is a hypothesis about applicability, not a default
for every fund or every assessment date. Check the official index, cover and
relevant scope before using it. Local Writer rendering is a check on the retained
original, not an official PDF or visual certification of every page. Normalized
passage comparison must retain its normalization and any mismatch; it cannot
silently replace the retained extract.

Skeptical audit: proceed with these bounded inspections. The baseline and source
identities are fixed; source research is independent of the failed model route;
no proxy can promote legal or tool completion. The important failure mode is
mistaking a fund-management delegation standard for a universal P10 discharge
test. Inspect scope and neighboring obligations before drawing that inference.
Another failure would be calling model-output rejection evidence that a native
tool is useless; the canaries did not run any complete tool arm.
