## Source qualifications and completed-cache identity

`sources.acquire_context` retains additional fields supplied with local roots.
However, `sources.packet_from_context` constructs units with inherited
`normative=True` and no fields for reconstruction, applicable edition,
extraction disagreement or the legal classification of page metadata. `Unit`
and `Packet` are strict schemas; extra root fields do not automatically enter
them. `semantics.inventory_request` sends the packet, reader role and
instructions. Both initial inventory roles and the inventory-repair path use
that constructor. The separate qualified preparation reaches
`investigation_answer.prepare_request`, after investigation. A qualification in
an input file is therefore not proof of early model delivery. Inventory
instructions ask readers to preserve uncertainty, but do not supply these
particular provenance facts.

The missing delivery matters. The corpus includes local reconstructions;
selected and whitespace-normalized historical UT extraction; unresolved edition
and applicability; Appendix extraction disagreements and unsupported visual
content; page titles/navigation; and unreviewed normative flags. These limit
what the legal inference can treat as authoritative. Removing filenames cannot
repair that semantic gap.

There is a distinct revision-identity gap. `CompleteInvestigation.run` binds
each root/retained source using URL, media type and raw byte hash. It derives
the outer revision and returns an accepted `execution_complete` dossier before
the core runs. `IntegratedInvestigation.run` also keys interpretation without
source selections. `Assurance.drive` includes `selection_hash` lower down, but
an outer completed-cache return can bypass that check. With raw bytes and other
settings fixed, a selection-only change can thus leave the outer key unchanged.
This follows from the inspected constructors; **no regression execution has
been performed**. No historical corruption is inferred.

`CachedEvidenceProvider.complete` keys responses by the actual request, schema
and settings; the journal also binds the route. It can distinguish a delivered
qualification, but cannot distinguish facts absent from its request. Context
injected after this cache or after request sizing would leave a gap.
`investigation_observations.method` already binds provider class, implementation,
route and settings. Its `source_identity` intentionally accepts exactly the raw
source fields. Add selection/context identity in parallel rather than silently
redefining raw-source identity or historical observations.

Copies of the inspected constructors, pre-transition mission and reset memo
are retained under `answer-target-review/retained-state/`, with a hash-checked
manifest. They preserve review evidence, not a substitute implementation.
