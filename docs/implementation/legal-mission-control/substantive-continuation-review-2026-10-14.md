The prior 78-node state is the comparator. No old attempt, result, source
envelope, live call, deadline or global ceiling may be overwritten. The new
nodes must be a strict local addition with one attempt each. Registration must
fail if an old task changes, a new live node appears, a prior result changes,
the deadline or call ceiling changes, or an archived baseline is missing. A
fresh name alone is not a repair.

The plan audit found a material source-baseline error before registration:
the retained Section I Handbook clause 6.8 concerns Product Key Facts
Statements, whereas 26EC22 footnote 1 cites clause 6.8 of the Code on Unit
Trusts and Mutual Funds. The latter retained Section II extract concerns the
register of holders and an appointed person. A P10 account must preserve that
source distinction and may not infer an exhaustive outsourcing standard from
either clause without further authority. This is a substantive source review,
not a parser-label choice.

because five quoted passages match.

Native graph controls have only a restricted interpretive target. A graph
adapter can check the consequence of supplied argument inputs; it cannot decide
which rival reading of P14 is legally correct, whether a Gatecoin factual
exception occurred, whether the 2025 scenario-seven language is reconciled,
or whether a court's relationship transfers to a Product Provider. The three
controls must use exact retained quotes, supported/adverse/unknown variants and
independent adapter receipts. A passing native status remains explanatory until
a complete matched answer uses and reviews it.

The graph is acyclic. Ownership branches are independent; a failed judgment
branch does not suppress P10/P14/evidence work. Account tasks wait for source
assessment completion but not whole-document qualification, because exact
quotations still permit conditional analysis with stated locator limits. Each
graph task requires its own account. The binding and release assessments wait
for terminal outcomes, including failures. Every node writes its own attempt
directory. The only shared reads are archived, hashed source and state inputs.
The local execution has a finite stop: if no authorized ready work remains,
the master reports `BLOCKED`, preserving the exact live/source/legal gaps.
