# Review of the consolidated route repair

10 October 2026 UTC. Executor skeptical review; no independent reviewer or legal
adjudication is claimed. Inspected the retained terminal failure, partial inventory,
core/scoped capacity results, actual provider composition, source-context verifier,
search consumer, complete-investigation dispatcher and answer/tool accounting.

The prior plan had three material weaknesses: insufficient baseline-core calls,
single-response schemas used for accumulated evidence, and receipt-level tool
accounting that could accept a retrieval for the wrong question. The new plan
addresses these together, without altering historical evidence or claiming that
lossless encoding proves legal entailment.

Audit findings resolved before execution:

- Baseline: retain actual rejected raw response and partial source counts; label
  historical-reading mixtures as hybrid engineering fixtures.
- Criteria: exact accounting and refusal correctness are engineering criteria;
  source-supported answer improvement is the separate product criterion.
- Fairness: original 13 baseline charges remain; matched future effort is at
  most 174 calls per arm, subject to unchanged stage limits until reviewed.
- Stop rules: one attempt, absolute deadline, no automatic eighth live method;
  failure of a local candidate blocks live dispatch but permits its planned
  corrections within the attempt.
- Defaults: byte bounds and review/batch sizes are explicit hypotheses, not
  empirically qualified production defaults.
- Environment: use the existing `.venv`, installed tools and CPU-only wrappers;
  no installation, GPU work, alternate model or account route is inferred.
- Useful evidence: tests must reach actual consumers and rejection paths, not
  merely round-trip a standalone codec. No command may mark legal completion.
- Permissions: use exact argv rules for fixed operations; protected rule
  installation is distinct from project allowlist documentation.

Decision: proceed with the bounded local attempt. Live execution is conditional
on whole-route qualification and resource admission, not on completing this
review. A live refusal is a valid program result and must name the remaining
problem instead of silently generating another phase or a smaller legal target.
