mandatory. UNASSESSED still leaves work unfinished, and reconciliation retains
all limitations. Coverage separately counts assessed pairs, actual executable
comparisons, unavailable meaning, blocked premises and missing perspectives.

Optional checks were bound to source and backend inputs but attached to prompts
without verifying the current reading. New v2 journals bind each check to its
candidate hashes; the model sees a check only if all of its checked readings are

unsupported smaller graph. When a request contains a subset, candidate checks
are computed on that exact subset before dispatch. Checks for a different graph
are omitted. Broad fidelity requests now carry reading hashes as well as the
declared meaning and actual representation.

Backend output cannot replace wrapper identity fields or mutate caller-held
inputs. Reports verify the journal backend against the bound investigation
method. Historical v1 reports retain their old shape and verify as history;
they cannot silently become v2 sessions. Exact previously issued requests keep
their original context across restart, even if later checks arrive.
