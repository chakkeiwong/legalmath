# Remaining product and integration work

The executable assessment program fixes a specific processing and evidence
integrity problem. It does not close the original legal obligations. The full
inventory is `remaining-gaps.md`; each obligation retains its exact missing
premises, source identity and closure requirement. Machine-readable originals,
every generated scoped pair and tool dispositions are retained in
`artifacts/legal-integration-assessment/2026-10-08/input-inventory.json`.

The register contains 46 open obligations. Categories overlap: 31 involve
authority/applicability, 31 factual input, 28 source interpretation, 27 normative
standards, nine question mismatch and five representation. Thirty-two of the
35 original readings remain unformalized. The separate generated product has
12 candidates, six unformalized, and 41 claims. All 492 scoped pairs must be
retained; 246 lack executable meaning. The 420 broad-fidelity pairs omit CONTEXT
claims and cannot substitute for the full scoped denominator.

## Substantive closure sequence

1. **Fix the target for each obligation.** Preserve its original source,
   candidate question, trigger/performance distinction and rival readings.
   Resolve a proposed question change as an explicit legal-scope decision;
   never silently turn responsibility into a trigger calculation.
2. **Obtain the named premises.** Match every missing authority to an applicable
   version, jurisdiction, date and pinpoint passage. Obtain the actual dated
   arrangements, appointments, operational and ownership records, supervision
   evidence and assessments named in the register. Public source retrieval can
   supply texts; it cannot invent client facts or a missing legal standard.
3. **Qualify tools on those problems.** Test jurisdiction citation coverage,
   case-to-target distinctions and source interpretation against independently
   assessed examples. Record tool-specific failure classes. Do not select a
   tool or promote a default on invocation count, XML validity, solver
   agreement, or a small number of model responses.
4. **Formalize the supported meaning.** For each of the 32 original unformalized
   readings, determine whether the existing Boolean/conditional profile can
   express the approved question. If it cannot, retain the reading and specify
   the required temporal, modal or deontic extension with counterexamples and
   semantics before implementing it. Open-textured standards remain explicit
   judgments unless a supported classification rule is available.
5. **Run the complete source-bound comparison.** Use a realistically funded
   full matrix, exact prompts and applicable tool context. Distinguish reviewed
   limitations, executable comparisons and legal closure. Independent review
   must adjudicate semantic scope and rival readings before any accuracy or
   release claim. Calibrate only after obtaining an appropriate labelled target
   dataset and a reviewed statistical protocol.

This is the closure sequence, not another automatically appended execution
phase. The current finite program ends after its evidence report. A subsequent
execution requires the specific data, target review and resource prerequisites
above; it must not reset the exhausted or partially consumed original grant.
