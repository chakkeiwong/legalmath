# Reference integrity and public-source preparation accepted

C0 passed 19 focused evaluation checks in 26.654 seconds. C1 passed 34 actual
Java/Python reference scenarios across four clean/altered cases, detecting all
four adverse executable mutants, in 23.077 seconds. No new model calls were used
in these two phases. The separate live phase has its own ledger and result.

The reference checker now rejects labels that disagree with executable reference
programs, including Boolean/integer substitution and an unwitnessed extra accepted
answer. Multiple permissible reference answers require explicit comparable
programs. Loading a study recomputes derived packet identities, heldout status,
family identities, assignments and call reservation; merely rehashing a forged
study no longer bypasses these checks. Shared source identities cannot be counted
as independent families. Invalid elapsed-time values cannot evade budget checks.

The two selected public families are family-office licensing conditions and the
RA13 client-money applicability question. Two further families—corporate
professional-investor assessment and suitability communications—are retained as
qualified examples without invented categorical outcome labels. Exact source and
scope details are in `reference-dossier.md`. The source/version caveats are
substantive: the investigator has not established the legal classification of
every hypothetical fact, historical applicability or the completeness of the
selected rule relative to all legislation.

The strongest alternative explanation for a successful replay is agreement
between an authored reference formula and an authored table that share the same
misreading. Different implementations and adverse mutants help catch coding
errors; they do not remove that source-interpretation risk. Public evidence,
explicit competing readings and independent outcome checks remain necessary for
stronger claims. This result supports executing the feasibility investigation,
not deploying either reference program as bank policy.
