## What was implemented

The reusable `assurance-investigate` command joins source extraction, located PDF
differences, alternative factual models, the existing breadth-first interpretation
search, source-fidelity checks, argument evaluation, independent cvc5 comparisons
and generated Java. Its durable journals retain exact inputs, output and binary
hashes, consumed actions and elapsed deadlines. A repeated unchanged completed
request reuses its original evidence; it does not add another model vote.

Two source-only abstraction roles and a missing-schema challenger can introduce
different actors, components, assessment units and time bases. Their readings
enter the actual search. Incompatible fact meanings remain incomparable. Missing
information and classification assumptions survive in the executable proposal's
questions and assumptions. Unsupported expressions remain unencoded candidates.

The cvc5 route independently encodes the supported RuleIR result semantics.
Actual Java runtime faults are compiled and challenged. The integrated Catala
baseline is commit `5290bc53`, merged into main as `67c9a12c`; the separate agent's
later native-converter work remains in its own worktree.

## Conditional references and Java

Five margin scenarios were frozen before live generation. After generation,
explicit full fact mappings to a hash-identified candidate were author reviewed.
They add a disclosed underlying-regime scope assumption. Actual ordinary Java,
Python, cvc5 and separately compiled Catala-to-Java agreed on all five: two TRUE,
one FALSE and two UNKNOWN results. Full Catala/Python result and trace checks
also passed. This is a conditional execution demonstration, not independently
adjudicated English interpretation or a blind accuracy estimate. See the
[worked case](margin-case-study.md).

The five STR reference scenarios remain unaligned and unexecuted. They ask
whether an e-Cert is required; the generated predicates mainly test combined
submission compliance or resubmission triggers. Equating those outputs would be
wrong relative to the frozen question. The [alignment note](str-reference-alignment.md)
explains the missing typed-control step. These cases stay in the denominator.

The [example manifests](../../../examples/integrated-assurance/README.md) include
all four raw public source responses. Each retained report's `independent.binaries`
entries identify candidate IDs, generated classes, build manifests and actual
JARs. The class uses the existing five-argument Java evaluation API. Input fact
meaning, evidence and dates are part of its conditional interpretation.

The final controlled evaluation detected eleven specified faults. Four shared
text omissions were invisible to two identical text routes but exposed by the
supplied raster-text comparison. Three hidden factual distinctions were invisible
to formula identity but exposed by explicit abstraction comparison. Four actual
Java mutations were caught by reference replay. This is authored complementary
fault detection, not an empirical independence or natural-error-rate estimate.

Three scripted source-to-Java workflows also exercised a clear case, a repaired
omission and an unresolved omission. Two produced the expected conditional
acceptances and one retained the required abstention; none of these three fixtures
was unsafely accepted. Their scripted model responses prevent a live legal
accuracy inference. Across the four live circulars there are zero independently
verified legal acceptances, so no conditional legal-error rate is estimated.

## Repairs actually executed

Repairs included the document-output restriction, fixture export into the isolated
solver environment, exact 6,000-digit numeral parsing, official SFC content-API
transport, retained abstraction uncertainty, bounded transport retries, source
inventory decomposition, persistent incomplete-stage reinvestigation and explicit
incomplete final reporting. Missing tool access was not inferred from the sandbox:
PIT's socket test passed in the trusted master environment.

The real STR packet exposed repeated identical dependency IDs and a nested
integrity failure that the new wrapper initially misclassified. The repair
preserves source occurrences, coalesces only identical dependency records and
propagates integrity failures before independent checks. A real-source regression
and failure-path tests passed. One additional reviewed P4 attempt was declared
for that diagnosed repair; all prior attempts, case budgets, elapsed deadlines
and model reservations remain intact.

The live phase used 85 calls: margin 18, e-IP 26, STR 18 and gifts 23. This includes
failed and interrupted calls. The shared ledger increased from 175 to 260 during
these investigations. The separate Catala agent had used 22 calls after the
preparation baseline of 153; those are preserved too. The declared ceiling was
273, within the user's existing maximum of 500. Revalidation of the completed
margin and e-IP cases after the dependency repair used zero new calls.

source interpretation or factual vocabulary. Independent compilers cannot remove
that common assumption. A source-supported counterexample to a provision, an
unresolved authority that changes its applicability, or an accepted wrong
reference outcome would overturn any stronger interpretation claim. The weakest
evidence remains independently established English meaning and completeness.
