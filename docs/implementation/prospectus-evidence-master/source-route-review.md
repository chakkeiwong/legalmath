# Source-route repair audit

The retained Nordea terms page embeds its documents in the first-results JSON
attribute. Ordinary anchor discovery therefore returned no PDFs despite the
publisher supplying them. The SEB and LVMH publisher pages also identify exact
document delivery hosts missing from the campaign host list: webapp.sebgroup.com
and lvmh-com.cdn.prismic.io. Add these two public hosts within the user-authorized
retrieval task; do not add wildcards or raise the request/runtime budget.

The repair parses JSON as data, retains the original responses, and writes a
separate recovered-link derivative. Failed-page navigation can suggest routes
but cannot establish contractual terms. A bounded file search avoids dumping
large minified source pages. Regression must show metadata links recovered and
invalid JSON ignored without code execution.

Skeptical verdict: accepted for implementation after this audit. This changes
discovery and policy, not classification semantics. Nevertheless rerun reviewed
validation and record both acquired Nordea PDFs as exposed under the next freeze.
Do not call them new holdouts under the repaired method. Consume a conservative
post-PDF repair cycle with old/new method hashes. Candidate acquisition failure
does not reject the prospectus research direction. No actor certifications,
accounts, private facts, dependencies or paid models are introduced.
