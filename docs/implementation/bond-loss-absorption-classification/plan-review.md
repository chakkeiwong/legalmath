# Skeptical review of the bond classification plan

Status: reviewed plan ready for implementation; public comparison-source
acquisition complete. L0–L4 implementation and classification tests have not run.
This is an executor review, not independent proof of English interpretation.

The user asks for a specific prospectus feature, not investment approval. The
current generic classifier tests possible product complexity. It cannot be
relabelled or treated as an unfairly weak loss-absorption baseline. Its useful
comparison is retrieval coverage; the proposed feature classifier, independent
formal predicate and common-input native targets answer the actual question.

The proposed controlled tests derive expectations from the declared formal rule
and exact source transformations, not human legal answers. Independent source
association checks can reject a false quotation, but cannot prove that every
English condition was captured. Negative classifications therefore need an
explicit document-set boundary and qualification. A currently absent controlling
document is missing evidence, not evidence that a clause does not exist.

Acquisition was deliberately bounded to four identified final PDF bundles,
without live model calls, with 45-second download limits and no automatic
retries. All downloads succeeded; all 201 pages produced text. The two junior
documents disclose interest deferral, and the base prospectuses contain
multi-product descriptions. These features make them useful confounding cases.
Their intended negative-control role remains a hypothesis until full source
analysis and dependency resolution. No accuracy figure is reported.

No material unexamined scientific default remains for the planning/acquisition
step. Implementation still requires exact commands, relevant environment checks,
source dependency records and the method freeze specified in the plan. A need
for fresh external model calls must be scoped under a distinct allowance;
historical exhausted grants cannot be silently reused. This plan does not
create or request another grant during the planning-only stage.

The plan passes the bounded skeptical audit after these changes. The strongest
remaining alternative explanation for an apparently successful classification
is a shared omission in source interpretation. Formal/backend agreement does
not remove it. A later controlling clause, scope contradiction or missed
exception overturns the relevant source-dependent result and triggers repair.
