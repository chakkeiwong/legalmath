## Why this is not yet legal assurance

The main unresolved issue is the English interpretation itself. Both live
methods used one model family, and the 11 expected answers were written by the
development author from the selected source. No independent adjudicated
reference set, second model family, reviewer-time study, or statistical error
estimate exists. Two methods can share an unnoticed exception. Agreement among
Java, Python, cvc5 and Catala establishes conformance of the encoded rule, not
correctness of the source-to-rule mapping.

The 232 restored pairs are evidence that the earlier routing exclusions cannot
be treated as settled. They are a queue for source-fidelity reassessment, not
232 proven errors. The three encoded children are executable artifacts, but the
parent/child judgments show why compilation is insufficient: one changed the
parent meaning and four were not established. The five R1 dependencies and the
separate 23EC52 appendix and incorporated legislation remain outside the
formalized packet. The 337 unresolved PDF differences may still affect source
meaning. The generated Java has no bank identity, authorization, data-freshness,
retention, calendar, deployment or release-control integration.

The result therefore supports a conditional prototype workflow:

1. preserve every plausible reading and every unresolved source condition;
2. compare only typed alternatives answering the same question with exactly
   aligned facts;
3. return a known Boolean only when all retained executable alternatives agree;
4. otherwise return disagreement, unknown, out-of-scope, unencoded or
   source-changed evidence with hashes and traces; and
5. send the residual queue to the next bounded investigation.

It does not support automatic legal release. The refreshed successor plan is
[assurance-after-round14.md](../../plans/assurance-after-round14.md); it starts
with the 232 restored pairs, the eight retained parents, the five authority
dependencies and the 337 PDF questions, then adds sealed reference cases and
an explicit common-error study before any accuracy or review-cost claim.
