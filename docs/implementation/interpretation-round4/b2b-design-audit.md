repair score. Acceptance requires a Java witness, zero gain for agreement,
rejection after any bound input changes, exact remaining-work records, and a
runtime test showing the evidence reaches repair scheduling. Proposed subjects
and fact meanings remain assumptions; no source-backed legal answer is inferred
from a program's output. An invalid replay is a repair trigger; an unavailable
model is unnecessary for these deterministic checks.
