# P7 proof inventory and evidence contract

The primary check compares the declared finite Boolean and extension semantics
with independent truth tables, complete-extension enumeration and actual Java.
The comparator is the formal source expression, never a legal answer label.
An unexpected omission, false unanimity, missed declared fault or mismatch
invalidates that checker/result and triggers repair. Source interpretation and
all-English coverage remain outside this contract.

Reuse lean.boolean-lowering.v1 only for equality of independently parsed source
and lowered Boolean expressions over TRUE/FALSE/UNKNOWN plus the existing conflict
flag. Inspect and run the pinned Lean 4.20.0 executable before kernel execution.
Retain actual kernel and finite Java enumeration receipts for the supported pilot
formulas. These are not proofs of the Java compiler or legal English.

The following theorem classes remain NOT_PROVED: branch inventory accounting,
preservation of unresolved premises through all product paths, dependency
invalidation, source-to-argument construction and general evidence classification.
A new InterpretationSemantics.lean prelude and registered verifier would need
serialization/runtime correspondence that this implementation does not establish.
Finite checks and fault detection are reported under their exact tested domains.

The P3 repair supplies an independent complete-extension oracle over all 512
three-node directed graphs. P7 supplies three-valued binary truth tables and all
nine pairs of extension values. Missing footnotes, source amendments, dropped
branches, actor substitutions, unknown coercion and condition inversion are
declared faults; identity tests detect data mutation, not a consistently encoded
but wrong interpretation. P4/P6 checks separately cover opinion-role substitution
and stale/swapped branch receipts. Save all results under the immutable P7 attempt.
