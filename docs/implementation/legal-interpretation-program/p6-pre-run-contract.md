# P6 contract and integration audit

Compare conditional Boolean source formulas with an independently parsed finite
reference and actual Java execution. Preserve the complete original packet,
semantic branches, questions, evidence, assumptions and settings in versioned
envelopes. Legacy enum reviewer_interpretation records a proposal, not approval.
The complete-investigator stage consumes retained legacy proposals in a separate
inventory and does not claim to reconstruct their source warrants.

Primary checks: identical scoped values, complete branch accounting, retained
reason sets and regenerated identities. Vetoes: missing/misbound source, wrong
actor or temporal join, changed settings, missing/swapped receipts, execution
disagreement, stage outside admission/observation. Explanatory only: counts and
elapsed time. No English fidelity, legal correctness, future generalization or
statistical comparison follows. Record immutable P6 attempt outputs and test
receipts, with all failed attempts retained.

Initial tests found tuple values crossing the strict canonical-JSON boundary and
a historical source unit exceeding the legacy 20,000-character bound. Repair:
normalize evaluator tuples before canonicalization; project only the units used
by the declared Reading into the legacy Packet and retain every other unit as a
hashed dependency, with the full unmodified original packet in the envelope.
An oversized referenced unit is explicitly unsupported, never silently truncated.

Evidence domain: Boolean facts/literals/not/and/or/if and conditional pilot
readings. Java is selected; Catala remains explicit in legacy qualification but
is not selected for semantic qualification v2. The optional stage is disabled
by default. Existing qualification v1 code remains untouched. Shared method
changes invalidate old frozen observations; the observation profile is v2.
