# Implementation audit before admission checks

Verdict: PASS for bounded development use; legal meaning and production promotion remain unestablished.

Reviewed the driver, source binding, geometry extraction and optional loader.
BASF selection requires explicit checkbox glyphs or bilingual Yes/No pairs;
it never activates a whole template. Unknown, duplicate or conflicting choices
fail. Geometry must be finite, in bounds, non-overlapping within each line and
wholly inside a reviewed region. Footers must be physical-page numbers. Every
word remains assigned once. The loader reconstructs all changed pages and
requires all others unchanged. A claimed complete legal reading is rejected.

Two driver defects were repaired before checks: failed baselines must remain
retryable, and mutable reviews need archived copies. Current-phase freshness
checks the current review; history checks snapshots. Prior receipt hashes are
chained, and numbered directories prevent reuse of partial attempts.

The 0.75-point line tolerance and split304/body-end775 coordinates are hypotheses
restricted to the inspected Deutsche pages. Adverse tests challenge crossings,
overlap, negation and mapping changes. No global layout default is introduced.

The frozen-reader comparison is descriptive. Counts are not promotion criteria.
The English column retains alternative CET1 ownership instruments; it does not
establish common-share-only conversion. Full BASF German clause construction,
dossier completeness and independent adjudication remain open.

Commands are local and bounded. Human response forms remain preserved.
