# Audit of the previously proposed four-method study

The earlier 288-call reservation is no longer automatically under-budgeted:
the user has authorized 500 additional calls. Availability of calls does not
make the old study executable without reviewing its methods and scoring.
Inspection during the F1 continuation identified material problems that must be
repaired before that particular comparison is dispatched.

`evaluation.score` requires the generated `subject` and entire free-text
`statement` to exactly equal the hidden reference. Fresh readers are not given
that wording. Meaning-preserving paraphrases will therefore abstain for a
string mismatch. This is an engineering abstention condition, not evidence of
poor English interpretation. The old reference convention also predates the
explicit trigger-predicate repair. It cannot act as an unquestioned comparator
for the new output convention.

The assurance arm still invokes the original monolithic inventory/fidelity
path. The live round-six work already demonstrated why a full-source matrix may
exceed one request or the proposed eighteen-call arm limit. Dispatching that
unchanged arm would repeat a known capacity failure and compare incomplete
execution with smaller arms. All four arms need declared actual task graphs,
common source access, equal ceilings adequate for those graphs, retained missing
execution and successful checkpoint reuse.

The public family-office case has now been used extensively for development.
Its earlier `heldout` designation is stale. Any revised study must identify this
exposure explicitly. The two clean/altered source families are a convenience
diagnostic set; variants are not independent family replications. No family
sampling assertion or ranking becomes valid because model calls are affordable.

This rejects the unchanged comparison harness as a measure of the intended
interpretation question. It does not reject ensemble search. The next repair
must separate public interface declarations from hidden expected outcomes,
version the reference translations, implement bounded task paths for each arm,
and run a synthetic adverse check showing that a paraphrase with the same
declared question remains comparable while a changed question or fact meaning
does not. Retain the old study and score as historical evidence. Do not spend
288 calls merely to produce an all-abstention table.
