# T00 implementation closure

This addendum resolves the master plan's starting engineering gaps. The existing
semantics and immutable fixtures remain authoritative. Every new schema is
generated by scripts/build_service_contracts.py; the existing three schemas and
examples remain generated by scripts/build_spec_examples.py.

Malformed JSON, duplicate keys, non-ASCII object keys, noncanonical numbers,
unpaired surrogates and invalid assessment times raise BoundaryError at the SDK
boundary. HTTP returns 422 with exactly `error: BOUNDARY_ERROR` and `diagnostics`.
No hash is fabricated. Hashable invalid bundles/snapshots produce an ERROR
EvaluationResult, using fixed diagnostic messages and sorted pointers.

Validation stages are schema, references/duplicates, types, cycles, time,
static-closure conflicts and evaluation. Structural messages are fixed rather
than dependency-library exception text. Runtime error pointers identify the
expression in the bundle. When several eager operands fail, the first error
in expression order wins; missing/evidence information includes every evaluated
operand. Conflict beats unknown. Source-span lists on trace nodes are the sorted
union of the owning rule's explicit citations; exception citations remain
inspectable in the immutable bundle. Rule references include target scope and
body roots in their children. A skipped body after false/unknown scope has one
SKIPPED root marker. When default guards fail, values/base are skipped; its
children are base followed by guard/value pairs in declaration order even though
guards execute first. This preserves both postorder and source child order.

Persist stream headers before events. Headers bind stream_id, profile, inception,
subject, category, actor, action, ordering_authority (nullable) and
profile_version. An optional reviewed initial snapshot explicitly binds its
reviewer, as-of time, state and evidence. Duplicate identical events are a no-op
even on retry; conflicting payloads or sequence reuse are errors. Every payload
is attributable to the header; a caller cannot redirect it through an URL.
Consent regrant requires an evidence identifier not used by an earlier grant.
Duty opening binds obligation_id and source_bundle_hash; no amendment migrates
that binding automatically. Replay identity includes the complete request and
the actual version of its backend, separately from decision engine identity.

Source revisions/derivatives/dependencies, source disposition, facts/supersession,
interpretations/issues/applicability, bundles/authors/reviewers, immutable build,
verification/release manifests, release intervals, stream headers/events, replay,
jobs/idempotency/audit are persisted. Canonical payload blobs retain full records;
foreign keys, uniqueness constraints and transactional checks enforce identity.
All mutations use BEGIN IMMEDIATE and caller-scoped idempotency. A failed mutation
rolls back its state, response and audit entry together. Interrupted jobs become
FAILED/WORKER_INTERRUPTED on restart; they do not publish partial results.

Java uses the same fixed diagnostic catalogue but its own engine identity. SDK
values and outputs are immutable, arbitrary precision, and date validated. A
generated policy class binds an immutable validated bundle and invokes the Java
semantic runtime; no Python, model or network service is needed by the JAR.
The manifest is external. Build -> verification -> release manifest -> approved
release is a directed acyclic sequence. Candidate compilation is independent of
approval. Only exact tested bytes may be exported for a reviewed release.

Service request models reject extra fields. A local bearer-token registry binds
caller names to roles; caller IDs/roles in payloads never grant privileges.
Every mutation requires Idempotency-Key. Jobs have explicit retrieval/cancel
operations. Requests and document downloads are bounded; all paths are server
selected. The public UI escapes source text and contains no executable model
output. API OpenAPI is generated from actual request models, retained as a
contract artifact and checked by integration tests.

Adversarial expectations A01–A16 from the master plan are preserved in
tests/conformance/contract-matrix.json with concrete test targets. Human owners
remain compliance (meaning, scope/definitions), data owner (freshness/FX/ownership),
and engineering/release owner (host mapping, identity, deployment). Local test
identities can exercise workflow but cannot resolve those bank questions.

## Final interface and resource decisions, 22 September 2026

The generated Java class is `hk.legalmath.Policy_<first-20-bundle-hash-digits>`.
Its static `evaluate(String snapshotJson, String ruleId, String validAt,
String knownAt, String mode)` returns strict JSON. The overload taking
`Map<String,Object>` returns a deeply immutable Map. These are the concrete v0.1
SDK interfaces; the proposed Java record wrappers are not required dependencies.
`EventReplay.replay(Map<String,Object>)` is the finite attributed-event SDK.
Malformed canonical Java input throws `Json.Invalid`, an IllegalArgumentException;
valid JSON with an invalid snapshot returns a hashed semantic ERROR result.
Generated classes are built only from bundles accepted by the Python validator.
The generic NDJSON Runner is a conformance harness, not a release selector.

HTTP is fixed at the [generated OpenAPI contract](openapi.json), with 22 paths.
Source, bundle, scope, coverage, issue, review, build, release, fact, snapshot,
event, evaluation and job operations share registry-based authentication and
caller-scoped idempotency. Domain JSON schemas are embedded in OpenAPI 3.1.
The `/docs` console uses packaged JavaScript and the same origin; it requires no
external browser resources. Source/model text is rendered through escaped text,
never as script. The UI pages are intentionally readable without authentication
within the localhost public/synthetic profile; mutation and API reads require a
local bearer token. Deployment on a shared network is outside this profile.

Sources fetched by the restricted HTTPS client retain their SFC/HKMA authority;
the frozen public corpus records RETAINED_PUBLIC_SOURCE. Base64 uploads are
UPLOADED_UNVERIFIED and cannot enter review or release. A declared URL alone
cannot confer official authority. Changing extractor versions adds a derivative
while retaining the source revision. A local manifest is a trusted operator input
whose raw and extracted bytes must match its hashes. Publication date is recorded
separately from effectiveness; no effective interval is inferred from publication.

Canonical JSON is bounded by 20 MiB and depth 128, with ASCII object keys and
exact safe metadata integers. Domain integers and money remain arbitrary-precision
decimal strings, subject to the input-size budget. Bundles allow at most 10,000
nodes and an expanded evaluator call depth of 128, including inter-rule references.
Oversized acyclic graphs return E_RESOURCE_LIMIT; cycles return E_CYCLE. These
engineering resource limits do not change the meaning of accepted rules.

Document retrieval permits 20 MiB, a 30-second total deadline and at most five
redirects, with hostname and public-address validation at every hop. PDF extraction
rejects encrypted files and more than 1,000 pages, and bounds retained extracted
text at 20 MiB. It runs locally using pypdf; this prototype does not provide an OS
isolation boundary for arbitrary hostile PDF parsing. Only local authorized authors
can import documents. A production intake service needs an isolated parser.

Comparison accepts the documented Boolean/integer fragment with explicit knownness
and a declared domain. The two solver checks share at most ten seconds; the service
worker has a thirty-second wall deadline, bounded CPU time and output file size.
Missing Java replay, budget exhaustion, unsupported constructs and inconsistent
domains never become equivalence claims. Model candidates allow three attempts
and zero tools; the current provider is a deterministic stub. Background workers
persist timeout, cancellation, launch failure and interrupted-restart outcomes.

Provision disposition requires an authenticated meaning reviewer distinct from
the author. Source inventory completeness still depends on that reviewer's supplied
inventory; the selected 23EC35 example retains all 51 independently enumerated
provisions. Reviewed initial consent snapshots also bind an authenticated meaning
reviewer. Local role checks and unsigned history archives demonstrate workflow
integrity, not enterprise identity or tamper resistance against a database administrator.

Amendment impact reports structural and definition dependencies. Semantic comparison
is a separate, explicitly requested comparison job. An unchanged structural report
does not claim equivalence. Changed rule versions require a new build, verification,
scope assessment and exact-manifest approvals. Existing duties keep their opening
source version; migration has no automatic implementation in v0.1.
