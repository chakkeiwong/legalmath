# Installed-profile repair: actual-method audit

The source inspection found two compressed runtime profiles and a package-data
pattern that does not select their suffix. The actual packaging comparison
will use two fresh copies of the same source tree and omit stale egg-info and
bytecode. The baseline receives the original configuration; the candidate adds
one pattern. No candidate wheel or installed consumer has been evaluated.

The isolated worker imports the installed package before any production module
and later verifies every loaded production module's path and file hash. It uses
full serialized products reconstructed from the sealed source-application
trial, with the expected complete answer retained separately. It runs the
ordinary consumer and one validly resealed make-whole-to-tax forgery. The
negative baseline must fail both actual compressed-profile readers with
FileNotFoundError naming the absent installed files.

The pre-run audit found that the master continuation register also binds the
live package configuration. Leaving that hash in place would invalidate the
reviewed edit mid-trial. The proposal replaces that live binding with immutable
before/after configuration files, retains all historical revisions, and the
worker enforces the exact live hash on each side of the single edit. This is a
reviewed configuration transition, not a relaxed integrity check.

The existing dependency environment is read-only and its files and resolved
interpreter are frozen. All build/install commands prohibit index access and
dependency resolution. Installed targets are fresh local directories. The
worker intentionally hides GPUs and refuses process/network actions during
consumption. Neither build success nor a profile import can substitute for the
complete answer comparison.

Actual-method skeptical audit: PASS for preparation and admission after the
source-application trial is sealed and recorded. The remaining uncertainty is
whether the expected packaging omission is reproduced by the actual backend;
failure to reproduce it invalidates that proposed attribution. A repaired wheel
must include every protected production file byte-for-byte, so a different
runtime code path cannot silently supply the missing behavior.

The completed source trial used about 3039 cumulative measured seconds. The
450-second packaging forecast fits the existing 3600-second ceiling, so no
time extension is proposed. Storage changes from 224 to 320 MiB including a
4 MiB reserve, admission 30 to 31. Prior resource
totals and unmeasured historical time remain visible. The preparation forecast
includes two source/build/install paths, controller copies and full serialized
answer evidence. No unchanged retries, hidden background jobs or source-tree
production imports are authorized.
