# Review before definition-binding execution

PASS after the semantic reconciliation. The candidate consumes the exact
verified P3 application supplement and adds a source-bound occurrence report.
It checks rule identity, rule group, checked premise quotation, explicit rule
extent, original raw quotation and all original question dependencies before
producing any binding. It refuses an application whose rule belongs to another
definition, including the shared U06/U07 amount span.

The independent expectation is frozen in `expected-content.json` before the
candidate. It requires all 62 records, 610 original associations and two
supplemental associations, and compares the complete answer. The production
module cannot mark the original definition report or question uncertainty as
resolved. It reports 582 uses without a reconciled governing binding, 15
explicit remainders and 3 other-purpose results; these are residual evidence,
not completion.

The normal and installed consumers are both required because a source-only
profile pass cannot prove delivery. The installed worker must inspect module
origins and compare its complete answer. Any source, profile, baseline or
import drift invalidates this package. Counts and test totals are explanatory.
