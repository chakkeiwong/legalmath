# FY2010 source requirements after the coverage repair

The original obligation is BES-DEP-08: the Bank's unaudited FY2010 release dated
31 January 2011, introduced by the second supplement dated 3 March 2011. The
supplement's cross-reference list selects balance sheet page 41 and income
statement page 42. Its restriction leaves other release information contextual.
The following reconciliation retains G01, G13 and RESIDUAL-03 alongside that
original obligation; none disappears because a finite source check passes.

The failure arose in our reference admission path. It checked each supplied
target's validity but had no FY2010 rule requiring the complete selected set.
The existing nine-month rule did not apply to this different supplement. The
200-cell profile protected its own reading and therefore could not establish
reference-set completeness. This is an implementation gap in our program; the
evidence does not show a fundamental limitation of an external package.

The actual Q1 release uses another supplement and a separate 299-occurrence
scope. Inspection shows that neither the nine-month nor the new FY2010 rule
covers it. That is a distinct, ready investigation under source-bes-dep-11:
reproduce an omitted financial-cell reference with the original Q1 consumer,
then review a repair if the same unsupported scope resolution occurs. Do not
infer Q1 behavior from the FY2010 result or reuse FY2010 row/period denominators.
