# Actual adverse results before installation

All 24 altered profiles were refused, with 23 repinned to exclude a stale
checksum as their explanation. The wrong year and unit reach the explicit
period/unit check. Missing cells fail the required cell schema. Cross-row and
cross-column swaps contain the other row/column's printed literal and reach
the image-reading mismatch check; the same check refuses lost signs, zero for
a dash, unchanged corrupted OCR and an automatic-correction authority claim.
Wrong note references, shared spans and invented boxes reach the exact original
association check. Missing separator, decoration or closing qualification
reach the complete fragment-inventory check; the omitted repeated row reaches
the complete ordered-row inventory check.

Changed PDF/image identity reaches the original-source check. False independence
reaches the reviewer-authority check; false financial validation or legal
selection reaches the corresponding scope check. Stale prior, graph and pin
reach the binding check. These are the intended substantive checks for each
alteration. The exact records remain in `controls-a.json` and `controls-b.json`
and will be replayed from the installed package without regenerating inputs.

The actual positive result retains three corrections beyond spacing, 47 rows,
94 money cells and every original character. Seventeen printed arithmetic
comparisons agree. The 2010 investing sum and both financing component sums
remain unknown because their printed components contain dashes. These observed
results do not turn the supplied image reading into independent financial
validation. The synthetic focused-test discrepancy is separate from the actual
source, whose checked known-value comparisons have no nonzero residual.
