# Incomplete interim reviews no longer gain audit support by changing category

The actual ordinary and isolated installed consumers now withhold audit support
for each of the three reproduced source variants: an added scope qualification,
an added conclusion qualification and changed accounting-criteria language.
Before this repair, each could obtain `SUPPLIED_SOURCE_SUPPORT` when supplied
with mutually consistent statutory-audit codes. The variants are explicitly
modified adversarial inputs with rebuilt source bindings; they are not original
reports. Their retained before/after answers show the change in use assessment.

The defect was in our applicability dispatch. The complete-structure matcher
controlled both positive validation and whether the interim-review checks ran.
A failed match and a different supplied category bypassed those checks. The
repair recognizes an applicable interim-review title or the retained original
source/pages independently of the full matcher, and returns incomplete context
when positive source structure is missing. The complete matcher still controls
positive support. This evidence identifies a local implementation defect, not
a fundamental problem in a third-party package.
