# Retain short stages after the measured baseline

The actual baseline completed in 104.88 seconds under the 120-second bound. Its
products and result are retained. To avoid operating close to that deadline, the
remaining cases use a separately frozen staged wrapper. No production method,
source reading, common input or original worker changes. The wrapper calls the
same current construction, interpretation, law, finance and final consumer methods.

Stage 1 recomputes P2 and retains exact P1/P2 identities. Stage 2 reconstructs those
same bound inputs, verifies stage 1, computes P3 and retains it separately. Stage 3
reconstructs/verifies inputs and P3, computes P4/P5 and consumes all five actual
products. Shared data is losslessly packed; the comparator reconstructs and checks
all content hashes. No stage receipt is a legal or whole-task acceptance verdict.

Audit PASS: identity equality and frozen method/input hashes make the split
observable. The primary source/semantic criteria do not change. The first baseline
is not rerun, no attempt or budget is reset, and pending tool sessions must be
polled before any dependent stage. The original and staged command manifests and
durations remain distinct. This prevents a measured near-deadline job from becoming
an avoidable interruption; it is not a claim about past stream-disconnection causes.
