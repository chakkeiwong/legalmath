# Selected page-131 procedure, source-bound and conditional

The original rendered base-131 page was inspected. Eleven complete operative
sentences in selected section 11 occupy lines1–31. Three adjacent subheadings
remain unknown text. The BASF Finance-only guarantee margin at lines32–41 is
excluded; section12 begins later and is unchanged. The source packet binds each
sentence to the already retained character map and original source graph.

The first sentence requires the issuer's website to carry meeting call and
precise participation/voting conditions from the call through meeting day. The
second is a requested information duty at the meeting only to the extent
necessary for proper consideration. The third refers to corresponding AktG
shareholder voting/counting rules unless the meeting call says otherwise; the
historical statutory text is not authenticated here.

The issuer must publicly announce resolutions at its expense. With a German
seat, the source adds prompt Bundesanzeiger and contractual section13
publication, with the named WpHG section50(1) publication sufficient. The
selected section13 publication clause is retained as a source-linked target;
the historical WpHG route remains unresolved. The issuer must also keep
resolutions—and original terms when a resolution amends them—publicly available
on its website for at least one month beginning the day after the meeting.

For voting without a meeting, the request must specify a voting period of at
least72 hours; holders may vote in text form to the chair during that period.
Other voting forms are possible only when the request provides them. The
request must state detailed counting requirements. These source rules do not
establish a particular call, actual window, cast vote, count, resolution or
amendment. The current law-applicability package addresses different page-130
notice/proof routes and is not silently imported as proof of these facts.
