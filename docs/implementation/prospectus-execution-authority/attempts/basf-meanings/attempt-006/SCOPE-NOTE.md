# Scope of the mandate hypotheses

The six default grounds are alternative bases for acceleration. The per-route
inputs do not establish six legally distinct rights or prove that every Boolean
combination corresponds to a legally effective mandate. Each input asks whether
the actual asserted right, on that modeled basis, falls within an effective
representative empowerment. A mandate covering acceleration generally could
cover all six modeled grounds; that application requires source and mandate
review. The isolated(a) case tests the behavior of an expressly assumed scope,
not the legal validity or existence of a resolution with that scope.

Likewise, the missing-mandate-fact baseline does not presume absence of a
representative. Actual authority, scope and the resolution's express exception
remain unknown. The truth-table worlds verify conditional implementation only.
This qualification preserves the source sentence and adds no statutory claim.
