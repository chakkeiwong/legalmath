# Review raster, vector and table coverage of retained Portuguese reports

Question: which source pages still require image/layout review despite available
native text, and do current downstream answers preserve that uncertainty?
Baseline: the 768-page native inventory from native-layout-cases, its two
image-reviewed layout pages, and retained source-report products including the
new Portuguese 2008 OCR evidence. The original PDFs are unchanged.

Evidence contract: retain source-bound page-level raster/vector indicators,
visually review nominated missing families, and exercise an actual existing
source/layout consumer on any new supplied reading. Check meaningful adverse
inputs. A complete page inventory is an engineering pass only; a page becomes
semantically reviewed only through retained image and reading evidence. No
threshold, native-character count, image count, numeric-line count or successful
render proves complete coverage. Record unreviewed pages explicitly.

Skeptical audit: nonempty native text failed on the seven Portuguese 2008 audit
pages. Conversely, art plates and decorative backgrounds can have little text
and many pixels without missing legally relevant prose. Native tables and
vector diagrams may contain abundant text but still need correct row/qualifier
relations. Reuse prior native metadata; add actual image placements and drawing
counts without classifying those proxies as semantic coverage. Prior English
pagination and previously selected OCR pages do not establish Portuguese whole-
document coverage. Inspect both positive and misleading proxy examples. Module
paths and original source hashes pin the environment. Audit passes for bounded
triage and development consumption, not automatic completeness promotion.

Default/assumption audit: native characters below 500 and an image covering at
least 20% of the page are convenience nominations, not learned or reviewed
semantic defaults. A largest image above 50% also nominates mixed pages even
with abundant native text. Numeric-line and vector counts nominate tables/
diagrams only. Their early diagnostic is image inspection, including art-page
false positives. All indicators stay descriptive. Existing source hashes are
integrity vetoes; altered coordinates/text/image bindings must reject in the
actual consumer. Product changes require a reproduced blocker and separately
reviewed repair; none are preauthorized merely to increase pass counts.

Execute the scanner with the reviewed PyMuPDF CPU interpreter under timeout
120, keeping one-second tool yields, live sessions and disk evidence. Retain
individual nominated page images and exact source readings before consumers.
Do not rerun completed full native extraction or OCR without new evidence.
Corrupt source, missing images or unavailable runtime veto dependent evidence;
preserve that failure and continue independent admitted work. Missing independent
review and unreviewed pages veto final coverage promotion only.

Artifacts: this directory's page inventory, image-review decisions, actual
consumer results, method/environment manifest, result note and output hashes.
After recording and refreshing, continue source-authority if selected.
