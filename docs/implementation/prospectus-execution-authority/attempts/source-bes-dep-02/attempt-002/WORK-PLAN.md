with retained provenance and actual downstream use, are the source acceptance

coverage. Wrong issuer/period or missing pages veto promotion. Changed historical

not rerun the old 62-hash helper merely to rediscover known code drift. If no new
source is recovered, retain a bounded acquisition result and historical integrity
