grammar handles some form structure, but source scope extends beyond same-row
geometry. The ratings paragraph qualifies earlier ratings across intervening
agency descriptions; BASF's margin expresses a German scope condition. A new
reviewed continuation must preserve exact quotations while testing an explicit
scope mechanism and independent source-family targets. It must not use the
reviewed expected endpoints as predictor inputs.

selection: this grammar was designed with the BES layout visible. Broader
unexposed forms could fail despite the seven exact matches. An independently
authored endpoint inventory on different table and prose families could
overturn its usefulness. Current evidence supports an optional suggestion path
only. The task remains partial; refresh selects the next ready work package.
