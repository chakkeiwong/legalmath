# Transfer verified geometry while retaining original source segmentation

## Question and skeptical audit

The lineage audit shows that the compiled patch retains every original word in
order on all five report pages, but its emitted PDF changes one page's groups
and clauses. Test a narrower assisted integration: copy only the patched word
rectangles into the original worker's exact words, order, block and line groups.
This preserves the original segmentation explicitly; it does not decide that
segmentation is legally correct or establish automatic boundary migration.

Audit PASS for one native-candidates continuation, cumulative four to five.
Original source/model/image/runtime identities and every word must match before
any position can transfer. The transfer consumes the compiled patch's actual
retained word boxes. It performs no new native build or OCR, edits no historical
worker, and never changes words, punctuation, order, groups, dates or findings.
It must compare fresh current full products on both baseline and candidate.

The callback arm is excluded from this transfer because its word boundaries
are different. Character-only alignment was disproved as a general semantic
criterion in attempt004. No search or guessed alignment is allowed here. The
known unpatched colon has missing usable geometry; its candidate position must
come from the validated patch, not a guessed/clipped rectangle.

## Evidence contract and assumptions

Main question: can the finite patch's positions reach the actual product while
preserving the complete original questions and source character/group structure?
The exact comparator is a fresh current unpatched-worker product using the same
five original pages, supplied corrections and report readings. Primary pass
requires exact full question objects, exact original native text units and OCR
word/group/nonspace identities, equal complete report facts/qualifications and
successful source/layout colon projection. Original source/image/model hashes
must remain equal. Changed parent/product hashes are expected and must be
verified, not forced equal. The new report must consume its own current products.

Wrong source/model/image, reordered/missing/changed word, nonfinite/out-of-page
box, unknown alignment or unequal actual question is a promotion veto. Invalid
artifact, timeout, method drift or ambiguous start stops the affected stage.
At most one separately reviewed changed harness repair is permitted, preserving
the failure. Counts and runtime are explanatory; no stochastic ranking applies.
No native default, general adapter, automatic segmentation, source authority,
independent legal acceptance, confinement, portability or whole-task completion
follows from passing this finite assisted transfer.

The old groups are an explicit preserved baseline, not truth inferred from the
new extractor. Exact positional correspondence is justified by the identical
word sequence and original byte/image identities; repeated words use their
ordinal positions, never string search. The fixed300dpi Portuguese model and
the existing supplied punctuation/report readings are historical baselines.
CPU-only execution hides GPUs before imports.120seconds per stage and60MB
retained physical bytes are execution limits, not performance metrics.
