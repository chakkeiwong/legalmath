# Fresh native candidate execution after the retained prototype

The current native cohort and callback-interface validations retain the source
comparator and missing families. Native-candidates attempt-001 already proved
that saved callback boxes preserve 266 word strings on Portuguese 2009 page 177
and let the spatial consumer select its colon. Repeating that saved-event test
would not close the fresh-ABI, emitted-PDF or downstream-consumer gaps.

The question is whether actual current native execution can supply valid
positions while preserving recognition, corrections and report meanings on
the frozen development pages. Candidate A changes the writer's group-axis
state. Candidate B converts fresh native callback boxes to page coordinates.
The comparators are the installed pinned writer, an isolated unpatched writer,
strict original intake and the existing optional unknown-geometry intake.

## Audit and engineering evidence contract

exact native library used by the retained trace. The complete writer translation
unit is retained. Review one narrower build hypothesis before attempting a full
library rebuild: compile that exact writer against the matching installed
headers/library in a local isolated shared object, with local symbol binding,
then call its writer in a bounded child. Fetch the same tagged tessocr.h from
the official source if no local copy exists. Bind its bytes, every included
header, compiler, source and library. This is an isolated native writer build
using the installed native dependencies; it is not a rebuilt complete MuPDF
distribution. No installed library is replaced.

First require the unpatched compiled writer to reproduce every retained PDF
word/box on page 177 and the known 21099 scale failure. A compiler/linker/ABI

patch may execute only after exact unpatched reproduction. Preserve its source
diff and compare actual emitted PDF words, character sequence and original-page
positions; do not substitute a Python arithmetic replay. No clipping or silent

and its explicitly discriminating local repair, not repeated blind reruns.

## Execution and retained result

Prepare/freeze the methods and source/environment manifest, then execute each
build or source-page command separately with timeout 120 and one-second tool
yields. Poll its returned session; never repeat a completed command. Use the
existing tfgpu Python for CPU-only native work with GPU intentionally hidden,
and worktree-pinned .venv Python for product consumers. Keep logs, full callback

the admitted attempt. If a consumer must be split, freeze its stage boundaries
before execution and bind every intermediate product. Limit this admission to
the seven named original pages, two native builds (unpatched and minimal patch),
one fresh callback arm, positive/adverse controls and one bounded diagnosed
implementation repair per arm. No package-wide/default claim follows.

Record the exact commands, HEAD, methods, sources, environment, CPU policy,
elapsed time, output paths and plan/result paths. The result must distinguish

not attempted and missing evaluation evidence. Include the decision and veto

partial evidence through the authority, refresh, and continue independent work.
Final authority acceptance follows current substantive results, not this plan's
