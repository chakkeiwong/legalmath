# Supplied orientation for the two failed original labels

## Question, comparator and skeptical audit

Native-candidates attempt002 already executed compiled writer and fresh callback
arms. Both complete labels on original Portuguese BES 2008 PDF page24 failed
in all three arms. The inspected original image shows Latin text reading from
bottom to top. Test whether supplying that region orientation to the same native
recognizer recovers the two unchanged development readings. This is a concrete
usage hypothesis; missing independent readers do not prevent the local test.

Audit PASS for one bounded continuation of native-candidates, cumulatively two
to three admissions. Do not rerun its seven-page build/comparison or edit any
sealed evidence. Retain its full-question mismatch and missing script families.
Use the original 300dpi raster, Portuguese model and library identities. Exact
whole strings, not character accuracy or favorable examples, are the criterion.
The supplied rectangles and direction make this an assisted preprocessing test;
success cannot establish automatic orientation, general OCR quality or adoption.

The whole-page retained callback is the protected baseline. Fresh arms use the
same fixed crop and border: no rotation, clockwise90 (the image-supported
hypothesis), and counterclockwise90 (an adverse orientation). Run all three for
both original labels. Do not choose the direction after reading OCR results.
No parameter search, new model, default change, source acquisition or install.

## Transform and actual consumer

Use pixel-edge coordinates. Let the crop's original-raster origin be(a,b), width
W and height H, and the white border be B. A clockwise quarter-turn maps crop
coordinates(x,y) to(u,v)=(B+H-y,B+x). The inverse is
(x,y)=(v-B,H-u+B), then add(a,b). For a rectangle, transform all four corners
and take their minimum/maximum coordinates; no clipping is permitted. Divide
original raster coordinates by300/72 for source PDF points. Counterclockwise
uses(u,v)=(B+y,B+W-x); its inverse is(x,y)=(W-v+B,u-B).

Verify these relations against a labeled nonsquare pixel grid transformed by the
image library, and round-trip actual boxes. Reject nonfinite/out-of-content
boxes before source-unit construction. Preserve every native character event
and consecutive native word/line grouping. Original image identity and rotated
derivative identity must stay separate. The trial payload explicitly covers
only the supplied regions; it is not a whole-page text-completeness claim.

The actual product check is source-unit construction followed by project_layout
with the original region, edition and exact string. Retain baseline and each
fresh result including failures. Adverse projections alter the source hash,
label, region/page and a character; invalid geometry must reject. Passing only
recognition text without this source-bound consumer is insufficient.

Pre-mortem: a tight supplied crop may do most of the work; matched fresh
unrotated crops distinguish cropping from orientation. Shared character strings
could hide a wrong inverse; pixel-grid checks, round trips and actual original
region projection constrain that error. Success remains local to two exposed
labels. A failure narrows the tested preprocessing hypothesis, not the method
or package as a whole. Independent source readings remain required.
