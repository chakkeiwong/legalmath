# Source-bound reference discovery reaches the product command

The public discovery API and `legalmath prospectus discover-references` command
accept selected text, a contiguous source partition, original text units and
exact full section labels. They do not accept expected mentions, BASF record
identifiers, reviewed targets or conditional answer profiles. Exact raw slices
are validated, and transformed text remains explicitly unbound to raw copies.

All60 original records reconcile to64 authored record expectations and61 distinct
mentions. The complete selected intervals, kinds and raw-source projections
match, with no extra candidates or unsupported-cue issues on this text. Original
duplicate/split line records are preserved. This is finite regression evidence,
not a measurement of unrestricted language recall. All49 original heading rows,
47 candidate lines and14 marker decisions remain in the retained original inputs;
only15 exact full section labels are excluded from mention discovery. Operative
prose in heading rows remains searchable.

The93 focused tests include21 independently authored grammar cases,17 adverse
provenance/schema cases, the original source reconciliation, source classification,
exact header handling, routing, and unchanged paragraph/profile regressions.
Development diagnostic001 exposed an omitted numbered statutory sentence and a
law name split across source lines. Those local grammar defects were repaired
before formal method freeze, with the original expectations unchanged. The
development artifacts remain retained and accounted for.

Thirteen service functions, including the complete consumer, are structurally
unchanged; only command configuration and dispatch changed. Sealed093 outputs
remain verified. This package executes the new discovery command downstream;
it does not rerun or claim new correctness evidence for the full093 answer.
The fresh offline wheel is checked against every production file, then used by
an isolated installed CLI whose complete report equals the ordinary report and
whose LegalMath imports all come from the installed directory.

The strongest alternative explanation is that a finite grammar fits the reviewed
source examples. The independent arbitrary-number/name, whitespace, list,
repeated-citation, malformed and negative examples reduce that risk; they do not
eliminate it for unseen languages or documents. A newly discovered omitted or
misclassified reference overturns coverage for its declared grammar and triggers
a changed source-first repair. The weakest substantive link remains destination
selection and the scope of the resulting legal rule. No package inadequacy is
established by the local integration and grammar defects repaired here.

All seven original gap classes remain open: general discovery across new sources,
definition discovery, historical/onward law, default(f), definition scope,
role-specific designated office and incorporation/question relevance. Actual
holdings and reader acceptance remain after the general build. External adviser
opinion is not a build prerequisite; ACTUS availability limits only its own trial,
and CDM/portability remain deferred by the user.
