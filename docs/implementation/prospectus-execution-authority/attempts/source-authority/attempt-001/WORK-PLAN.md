# Edition identity, acquisition and historical availability

Question: what do the retained BES issuer archive receipts establish about
the six 2008–2010 English/Portuguese editions, and what external evidence can
support their publication or historical availability? The baseline is the
sealed conditional report answers and the unresolved fourteen-source register.

Primary criterion: a source-bound inventory must distinguish exact bytes,
archive link, complete transfer, local acquisition time, report date, PDF
metadata, publication date and historical availability. Any stronger finding
needs its own evidence. Run the real report-scope consumer with the retained
readings and require unsupported external facts to reject. Integrity mismatch
vetoes the affected source; exact date spans inside a report do not authenticate
publication. No independent legal acceptance or exact historical-byte identity
follows merely from today's issuer link.

Skeptical audit: re-downloading the same files cannot answer a historical
availability question. HTTP Last-Modified reflects this server object, not
necessarily original publication. PDF creation dates and audit dates are
different again. The supplied external fields in report_scope.admit currently
reject unconditionally; document that implementation boundary rather than
falsely claiming that new evidence is already integrated. Use existing source
bytes and receipts, then at most four bounded read-only archival queries to
seek a dated capture or contemporaneous filing. A search failure is an access
result, not evidence that the source never existed. No source dates may be
filled from convenient metadata. This bounded plan passes the audit.

Assumptions: retained issuer-host links establish the observed route only;
their historical ownership and the exact incorporated edition remain review
questions. Retrieval clock values are acquisition observations, not statutory
publication dates. An archived capture could supply an upper bound on observed
availability only if its timestamp, source URL and retained content/identity
are checked. Byte-equivalent copies can corroborate local identity but do not
provide independent authentication by themselves.

Execute local inventory and actual consumers with worktree-pinned imports,
CPU-only settings, a 120-second outer timeout and one-second tool yields.
Archival requests use HTTPS, a 15-second ceiling and 2 MiB limit per response;
retain headers, body and outcome. Network denial stops that route; continue
independent local evidence. No package install or live model call is needed.
Retain input/method hashes, actual command/environment/time, controls and
decision note in this directory. No stochastic ranking is attempted.

Promotion vetoes: changed source/receipt, unsupported historical date,
wrong language/edition, or absent consumer controls. Continuation vetoes:
shared evidence corruption or unavailable necessary runtime. Archive access
failure blocks the stronger historical finding, not local review or the next
independent task. Explain open evidence and implementation gaps separately.
