The admitted task requires real table, rotation, vertical-writing and
bidirectional pages with reviewed readings. The accepted five-case cohort and
callback interface are the comparators. This bounded work package first checks
the three already retained Portuguese issuer reports (2008–2010), then freezes
source-bound page evidence for any useful family found. It does not replace

## Evidence contract and skeptical audit

Question: which required layout families can these retained legal/financial
sources actually supply, and what prevents their use in a matched consumer?
The source baseline is the verified inventory at
`bes-original-acquisition/source-inventory-2026-10-12/result.json`, the three
original response bodies and their acquisition receipts. The exact source
hashes must match before extraction. The current strict and optional geometry
profiles remain the product baselines.

Pass for this preliminary package means a reproducible source/page inventory,
retained page images and exact source evidence for nominated cases, a separate
list of absent or unverified families, and retained downstream results where a
bounded consumer is justified. Source hash changes or parse failure invalidate
the affected inspection. A real coverage shortfall vetoes promotion to that
family; it does not stop independent source work. Counts, digit density, PDF
rotation, writing-mode flags and Unicode categories only nominate pages. None
proves semantic reading order, a table relation or independent legal review.

The audit finds two risks in treating the task title as directly executable.
First, rotating an ordinary Latin page cannot supply true vertical writing;
PDF rotation and text direction must be recorded separately. Second, numeric
tables may retain text yet lose header/row relations. Image review and a real
consumer result are required before claiming those relations work. A third
limit is that the task has no implemented acceptance validator. The actual
work can be retained, but the authority must not mark this task complete.
This package therefore cannot authorize native-candidate promotion or close
the parent obligations. Audit verdict: proceed with the bounded source
inspection under these restrictions.
