# Separate Finance 2009 original not recovered

Three archive metadata requests and one archived issuer index retrieval did not
produce the named original. The exact-date query returns the Bank's financial
reports, Espírito Santo Financial Group and unrelated funds. The issuer search
also returns older reports and a 2005 Finance offering circular. These are
discovery hits only; none is evidence of the separate 2009 original.

The actual 22 January 2011 **Outros Relatórios** index identifies its 2009 and
2008 downloads as **Espírito Santo PLC**. That issuer heading is decisive: these
links cannot be silently reassigned to BES Finance Ltd. A second download was
unnecessary because the index itself excludes the candidate issuer. This
sharpens the next search towards the archived Downloads page or the Luxembourg
exchange's issuer filings. It does not prove absence elsewhere.

The primary original-source criterion is unmet. Wrong-issuer/type candidates
are excluded, but the engine is not invalidated. Search ranking and query
semantics are uncertain: returned hits include older documents despite the year
term. Bounded top results therefore cannot support exhaustive absence. An
unindexed or scanned Finance report remains a plausible alternative.
