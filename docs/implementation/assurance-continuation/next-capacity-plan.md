# Measured next capacity repair

This is the concrete successor to the executed 263-unit diagnostic, not an
assertion that its unfinished whole-source reconciliation passed. The controlling
machine-only proof/qualification requirement and original live limits remain.

The current optional locator compaction gets the complete source through initial
interpretation and coverage requests. A synthetic run retaining one concern for
each of 263 real source units reached all coverage pieces, then stopped before
the final model dispatch. The exact final request was 382,396 bytes. Its main
components were coverage (221,974), reference table (68,333), source packet
(59,866) and echoed response schema (26,054). These are measured serialized
component sizes, not model-token or legal-accuracy estimates.

## Causal target and earliest checks

First inspect repeated representation within the retained coverage. Propose a
versioned, readable table format with explicit columns for the unit and concern
records. Source quotations may refer to the unchanged supplied units rather
than repeat their text, provided a deterministic decoder reconstructs the exact
old records. Repeated schemas or locators may be represented once. A semantic
summary, truncated list, dropped rationale, removed concern or hidden source
unit is not an acceptable repair.

Before touching the model route, require the codec to round-trip every actual
coverage record exactly, with source, reading and coverage hashes unchanged.
Mutate a table column, index, quote reference, question, source edition and
cross-piece link; all detached or malformed inputs must fail. Test different
table shapes, long unique rationales and multiple unrelated concerns. Repeated
synthetic prose compresses easily, so the measured fixture alone is insufficient.

Next reconstruct the exact final request using that codec. Record its byte count
and remaining headroom under the existing 200,000-byte setting. If it still
exceeds the limit, report that result. Do not silently increase the context
limit or infer that independently checked pieces settle global interactions.
A justified larger-context option would need its own explicit provider
capacity/latency/output contract and observed evidence; it is not the default
repair specified here.

## Integration and acceptance

The model must receive the full source, exact question definitions and complete
decoded meaning of every concern. The new input encoding and output identity
contract need a distinct protocol version. The final output must still account
for every concern and question, and a reading revision must still invalidate
coverage. Run the actual retained capacity fixture and structurally different
challenges, then the complete investigation regression. Keep the original failed
capacity result and every live issue reservation.

Acceptance is exact preservation plus executed bounded processing. A model's
agreement across encodings is only a proposal-comparison diagnostic; it does not
prove legal meaning or promote a default. A later live attempt needs an eligible
original issue and unspent authorization. Missing either remains a resource
qualification. No human reference labels or quality approval enter the method.

Other measured work remains separate: deterministic references for executable
quotation text; a declared date semantics and proof profile for the eight
encoded UCITS readings; and exact source/applicability premises in the six
inherited authority questions. None is closed by making the coverage request
smaller.
