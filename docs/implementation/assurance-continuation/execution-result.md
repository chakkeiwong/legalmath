The continuation implemented exact source references, breadth before follow-up
depth, complete declared-question coverage, bounded n-ary addition and the
connection to shared machine qualification. It used the 37 remaining authorized
model reservations. The whole four-circular investigation is still incomplete,
and neither English legal correctness nor accuracy on future circulars is

## What changed

The model now selects closed source-span identifiers and software retrieves the
unchanged source characters. Packet/request identities, Unicode codepoints,
adjacency and uniqueness are checked; the existing source-support validator still
decides whether a response is admissible. All 36 returned live source selections
resolved successfully. Selecting real words does not establish that those words
support the proposed interpretation.

The optional round-first scheduler reaches every eligible initial batch before
spending on follow-up depth. Paired contexts do not see each other's current
answer. The split single-reader protocol retains every declared question, every
source unit and all cross-piece concerns. A changed reading invalidates its old
coverage. Failed calls, rejected responses, missing perspectives and original
deadlines remain recorded.

Addition now accepts bounded expressions with more than two operands. It keeps
their order and repeated terms and leaves existing binary representations
unchanged. Lean checks the exact integer/tagged-missing addition proposition.
The actual retained expression `D + I + D + I` was replayed without dropping
operands. Seven conditional cases ran through each of Java and Catala, for 14
backend cases, and the dropped-term mutation produced a separating witness.
The product itself retained unresolved source premises and executed zero target
cases through that qualified route. The separate hypothetical runs are not
unconditional product approval.

The qualification adapter binds the exact source, proposed reading, question,
assignment and method to the checked proposition. All nine retained UCITS
readings received verified records: eight date-containing formalizations remain
outside the current constructor proof profile; one is unencoded. That replay
selected no runtime cases and reported zero executions. The new adapter reports
these limits rather than manufacturing a proof or convenient factual input.

The compiler checks also exposed excessive schema-validation work on a
twenty-operand expression. Conservative discriminator pruning removes only
logically impossible branches. Comparisons with the original validator and
actual backend execution checked the repair. A later isolated regression exposed
an old absolute appendix path; the portability repair uses the already frozen
source reference with its original task, URL and byte hash. The old receipt is
preserved, and the 15 focused portability tests pass, including a symlink escape
and a changed media type.
