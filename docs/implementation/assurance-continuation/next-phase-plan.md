## Repair and refresh mechanism

Each phase must define its exact inputs, comparator, expected failure, executable
command, environment, output and acceptance before running. Keep the general
source-to-question contract fixed across circulars; no circular-specific expected
answer may be embedded to make the study pass. Start with a focused diagnostic,
then the affected integration checks, and run a full regression after integration.

A failed phase retains its manifest and output. A retry names the causal repair
and an actually executed focused reproducer, preserves earlier spending and
deadlines, and consumes a predeclared retry allowance. Refresh the next plan after
both success and failure with the measured remaining work. A size failure in D1
may require another representation repair; it does not invalidate unrelated
date work. A failed semantic witness vetoes that implementation until repaired.
A source uncertainty remains a qualified question rather than a fabricated
answer. Do not move an exhausted action to a new directory to restart its budget.

All execution commands must use a reviewed narrow wrapper and the tested Python,
Java, Lean, Catala and document environments. Reuse the approved continuation
prefix only for commands its program actually accepts. Add a distinct narrow
wrapper approval for a distinct successor program if required by the execution
environment; an allow-list entry never enlarges a model grant.

## Evidence and review

Primary engineering criteria are preservation, executable conformance and the
exact checked formal proposition. Lost questions, accepted detached evidence,
hidden scope changes, false proof attribution or refunded attempts are promotion
vetoes and repair triggers. Missing required evidence, invalid environment or an
exhausted authorization is a continuation veto for the affected action. Test
counts, request sizes, model agreement, elapsed time and descriptive case results
are explanatory diagnostics; they cannot become English-accuracy measures.

Skeptical audit: the earlier work showed two readers making the same invalid
executable judgment, and a split response reaching every coverage piece while

observed mechanisms without selecting a favored interpretation. D3 strengthens
