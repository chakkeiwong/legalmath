# Schedule all frozen sources after the measured mechanism pilot

The twelve-pair workload has produced three complete batches: both initial
perspectives and both required follow-up perspectives validated. Earlier pilot
revisions already executed the same retained packet/readings through exact
question assignment, independent backends, five supported Lean certificates and
the replay dossier. The source, candidate and question identities must be checked
before using this evidence as an engineering scheduling diagnostic.

The original scheduling condition waits for the entire first circular's matrix
before starting another frozen family. The observed 368-pair workload can consume
most of the remaining shared grant. That gate is inappropriate for the stated
four-family question: a resource-limited first matrix would prevent the three
other independently executable investigations from starting. Completing a small
mechanism pilot can justify parallel scheduling; it cannot justify claiming the
whole circular or study complete.

Amend scheduling to run the four frozen task directories concurrently after a
hash-bound review of those actual pilot records. Preserve the entire unfinished
pilot matrix, every frozen task, the 120-call per-arm ceiling, 460-call study stop,
40-call evaluation reserve and overall 500-call grant. The comparison remains
descriptive with unequal actual expenditure. All original study acceptance
criteria remain: every required joined investigation must complete to pass S8.

A controlled stop preserves the currently reserved call and its transport. A
fifth S8 attempt creates an explicitly identified continuation revision. Reuse
exact completed scoped responses, as well as core/question proposals, only after
journal, source/schema/route and allowance checks. Carry failed and interrupted
requests into the same per-pair/perspective counts and earliest deadlines. Never
reuse an incomplete response or count a cached response as a fresh judgment.

Before execution, test scoped reuse without dispatch, changed-question
non-reuse, interrupted-request accounting, full task scheduling from the reviewed
pilot and rejection of an absent or altered pilot receipt. Review the actual
receipt against the retained 36 pairs and immutable replay. Full regression
previously passed 1,200 tests with no skips; these orchestration changes require
current focused checks and a new full regression before final acceptance.

This repairs resource allocation and recovery. It does not alter a source
interpretation, remove an uncertain row, replenish semantic rounds, promote a
candidate, or promise that all four matrices fit in the fixed remaining grant.
