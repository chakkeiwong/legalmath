# Coverage review for G4

The four-question model matrix is a useful development comparison, but a generic
tool-role mapping alone does not test the 46 individual gap records. The three
G1 Boolean controls are paragraph 14 examples; they are not the three formalized
paragraph 10 readings among the original 35. Those denominators must stay distinct.

Within G4, run retrieval on a query derived from each original gap's recorded
missing premises and on each retained reading. Keep all identities and exact
offsets. Existing role-response citations provide descriptive source-location
targets only where the quoted text occurs in the frozen corpus; missing labels
remain explicit. These are neither independent gold answers nor evidence of
legal resolution. Do not tune the retriever to these labels.

Also round-trip the actual three original Boolean formalizations through the
same external schema adapter. The remaining 32 retain an explicit unsupported
formalization disposition. Preserve fact definitions, judgment requirements and
source references beside the expressions; passing an AST check does not validate
these meanings or discharge criteria.

The target-case controls should exercise the existing precedent API with proposed
absent-consent, changed-terms and different-relationship factors. The API checks
references, not target truth or analogy. Record that distinction and require
authority to remain unresolved. Corrupt source links and falsely attributed
holdings must be rejected. A permissive reference check must not be reported as
a successful consent classifier.

Audit verdict: proceed under the existing G4 coverage obligation. These are
bounded, deterministic offline diagnostics using the existing source and tools.
They add no provider calls, change no legal baseline and establish no new client
facts. Current-law treatment, source equivalence and factual application remain
separate. No additional phase, budget or permission is required.
