# Remaining work after adoption execution

The immediate delivery target is a finite assisted service for explicitly named
instruments, dated questions and supplied scenarios. Complete source-backed
construction and interpretation before independent acceptance. The current
controller is reusable; rerunning unchanged inputs only reuses receipts and
cannot supply missing evidence.

The optional Docling trial is closed as rejected. Further parser work is justified
only by a new specific mapping/attachment mechanism with a bounded test on the
same failed pages. The original extractor remains the working baseline. Do not
expand the corpus, tune a model indefinitely, or install ACTUS/CDM merely because
the legal-source work remains difficult.

Repair admissions use this exact entry point:

```text
python3 -m scripts.prospectus_delivery --program adoption repair --record /tmp/reviewed-record.json
python3 -m scripts.prospectus_delivery --program adoption run
python3 -m scripts.verify_prospectus_adoption
```

The record contains `obligation_id`, `phase`, `name`, `before_sha256`, `content`
and `reason`. `before_sha256` is null only when the input does not exist; otherwise
it must match the current admission. A4 accepts `coupon.json`; A6 accepts
`facts.json` and `review.json`. A successful admission means the program consumes
changed input, not that it accepts the legal interpretation. The next-phase and
repair records refresh after execution. Every legal source/meaning change must
be reassessed through the affected installed report.

## Audit and continuation rules

Baseline: the final adoption receipts and retained raw documents. Primary
criteria are source fidelity, faithful reviewed meaning and correct downstream
answers/calculations for the frozen scope. Source corruption, leakage, an invalid
comparator or an exceeded run budget stops the affected experiment. A failed
candidate triggers its named repair and does not stop independent source work.
Counts and agreement alone cannot promote a result. No population accuracy,
automatic transaction permission or authentic independence is inferred from JSON
declarations. Paid services, new external communications and broader deployment
are not required to prepare any of these reviewable inputs.

Audit verdict: PASS as the next sequence, conditional on the listed source and
human evidence. The current bounded implementation/trial program is finished;
these substantive acceptance obligations are still open. The next discriminating
work is a complete reviewed contract and interpretation, not another unchanged
master-program run.
