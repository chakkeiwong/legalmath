path did not invalidate the Boolean or coupon checks, and it does not reject

## Reproduction and next work

From the worktree, run `python3 -m scripts.verify_prospectus_adoption` for execution,
regression, replay and current-state verification. Each new verification attempt
is retained. Individual jobs and repairs use the exact commands in
[the executable plan](../../plans/prospectus-adoption-execution-2026-10-07.md).
[The refreshed controller record](next-phase.json) binds each next-phase plan to
its parent receipts; [the remaining-work plan](NEXT-PROGRAM.md) states the
substantive repairs that still need source work or external evidence.

Large generated products are preserved locally and losslessly archived through
`checkpoint/manifest.json`. Ignored input snapshots have their own
[reconstruction manifest](snapshot-manifest.json): retained source paths, exact
hashes, pinned model URLs, and compressed copies where an earlier input no longer
matches the working source. Restore historical checkpoints first, then the
adoption checkpoint and snapshots. The tools do not automatically download
missing models or fabricate historical sidecar bytes.
