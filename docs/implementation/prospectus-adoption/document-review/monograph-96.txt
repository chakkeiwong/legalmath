The optional Z3 adapter agrees with finite evaluation on the declared Boolean test cor-
pus. The checks cover a small grammar with all its partial and conflicting assignments,
and selected formula families across 8,190 complete assignments using one to twelve
facts. This is not an exhaustive test of every formula over twelve facts. Larger exam-
ples exercise the installed interpretation path. An inconsistent premise set produces a
conflict; missing premises and computational timeouts remain distinguishable forms
of uncertainty. Typed reference checks also retain missing targets and unsupported cy-
cles as unresolved. Translating German definitions, exceptions and priorities faithfully
remains a separate task.
The Docling trial failed its declared acceptance criterion. The pinned layout model pro-
cessed BASF file page 112 and Deutsche file page 52 on the CPU, with OCR and table
recognition disabled. After correcting the adapter’s mixed-font ordering and list mark-
ers, 14 of 53 designated critical source lines still lacked complete exact character maps.
Some failures arose from joining hyphenated text; others involved geometry and read-
ing order. This result means that the candidate could not recover those occurrences un-
der the required mapping, not that every affected line had disappeared from the PDF.
The governing relation between a margin and its clause also remained unresolved. The
service keeps its existing extractor, and the trial does not expand to further pages.
The annotation exchange was more successful. A real UIMA XMI round trip through
dkpro-cassis preserved the supplementary Unicode character, combining mark, re-
peated text, discontinuous evidence groups and semantic relation in the test packet.
The bridge explicitly converts between Unicode code-point offsets and UTF-16 code
units and rejects changed source text. The implementation and guide are matched
to INCEpTION 38.0, but an INCEpTION server and independent readers have not
yet used the project. Successful file exchange establishes preservation of the supplied
annotations; it cannot establish their legal correctness or the readers’ independence.
