2.6.6 What the tool trials changed
The next investigation, on 7 October 2026, tested whether established tools could repair
specific failures in the prospectus service. It retained the existing extraction and finite
Boolean evaluator as comparators. Nine documents supplied 326 selected file pages
and 3,047 retained text units. For 289 of those pages, the printed page label remains
unresolved; a file index is therefore not presented as a verified printed citation. These
documents had already informed development and cannot supply an independent ac-
ceptance sample.
The construction repair makes omissions visible. Every interval in the selected BASF
body now has a recorded disposition, including unresolved material. The checker still
reports 1,018 unresolved intervals and the candidate retains 83 brackets. Complete ac-
counting consequently establishes where the work stops, not a complete German con-
tract. A shared definition can serve several branches: excluding one use no longer
erases another. A field whose rendered value differs from its cited quotation also re-
mains unresolved until that transformation is justified. Versioned runtime validation
checks the admitted construction; a separate published JSON schema has not been
added.
