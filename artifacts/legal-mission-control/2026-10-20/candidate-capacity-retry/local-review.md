# Review of the candidate repair and saved-preparation continuation

The frozen predecessor contains four PREPARED findings, not four failed
syntheses. The optional candidate requests exceed the local 12k-token limit;
evidence and Gatecoin also exceed the earlier byte envelope. The wrapper's
all-phase success condition turns these optional failures into acquisition
failures. These are reproduced implementation defects, not evidence that the
legal task is impossible or that the service lacks the requested capacity.

The exact production candidate replay compares each failed request identity
before any transformation. Its expansion preserves every source character,
quotation map, field and response schema. The separate criticism probe uses
the same source sets with explicitly synthetic candidates. It tests the real
constructor and transport; actual model-generated criticism inputs still need
their own ordinary preflight and output validation.

The completed-preparation path authenticates the retained input, source store,
accounts, dispatch population, all reduction memberships and results, and final
finding. It repeats source, account-population and citation validation but no
completed model call. The production-entry replay withholds optional admission
on purpose and requires PREPARED findings unchanged from the real predecessor.
No debugging response is offered as legal evidence. Altered-source, missing-
account, lost-membership, changed-lineage and changed-result tests must reject.

Baseline answers now use the same saved findings without candidate/criticism
dependencies. The BM25 arm requires retrieval only. Formal and argument tools
retain their own generated candidates, criticisms, native operations and
downstream evidence requirements. Optional failures remain visible in phase
diagnoses; authority/integrity errors still block preparation.

The delta from the frozen worktree was reviewed, including registration paths,
phase routing, schemas, mutation bounds, task history and worker commands.
The review found and repaired a resume assumption: a fully reused preparation
may have no dispatch journal if optional admission fails before dispatch.
The new path writes an empty journal bound to the same input and call ceiling.
The worker also runs the ordinary local master after live work, then refreshes
and verifies, so ready local descendants are not left merely because a live
pass ended. No attempt, charge, deadline or service reserve is reset.

validator incorrectly expected 8,100 in the local scheduler's call-ceiling
field. The frozen scheduler has zero model-call authority; the separate live
grant has the 8,100-call ceiling. Preserve the scheduler's original value and
check the live grant separately. This correction changes no allowance. The
registration tests use the actual zero-authority scheduler baseline.

The nested historical check then found two archive paths for the same original
diagnosis bytes. Preserve the earlier established alias in historical
projection and binding instead of substituting the new duplicate. Both copies
retain their exact hashes, and the frozen baseline is unchanged. The ordinary
conflicting-alias guard remains in place. A targeted test rejects a tampered
