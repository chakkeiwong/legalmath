a case. Separate requests produce initial readings without showing each request the
other answers. Another set of requests inventories the source’s requirements and qual-
ifications. This second view helps expose an exception that all the proposed readings
might miss.

4. Challenge the interpretations
Tree search organises successive revisions of a reading. Breadth-first search visits the
shallower alternatives first. Upper Confidence bounds applied to Trees (UCT) balances
previously useful branches against less-visited ones. These are ways to choose the next
investigation, not probabilities of legal correctness. Both are implemented with finite
work limits.
