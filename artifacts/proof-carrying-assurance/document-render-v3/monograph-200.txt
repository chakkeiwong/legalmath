6.34.4 The future-circular path
The bank is concerned with future circulars, so the product must fail visibly when a
new clause does not fit its current grammar. The dossier has an EXTENSION_REQUIRED
question for this case. It names the new source passage, the absent interpretation family,
the RuleIR construct that is needed and the evidence required from the legal owner. The
controller does not select the closest historical family merely because its Java emitter
compiles.
This is a principled extension path rather than an assertion of universal coverage. A
future source is first added to the authority catalog and source inventory. Its unresolved
choices are enumerated before candidate generation. The new family receives its own
controlled-language and argument records. A formal encoding is accepted only after
its types, time model, result categories and source quotations are reviewed. Existing
programs can be reused when the new rule is proved equivalent under the declared
mapping; otherwise a new artifact is generated. Old decisions remain tied to their old
source edition.
ResearchAssistant can supply retrieval, parsing, local paper and source retention.
DynareMCP offers a pattern for recording hypotheses, dependency graphs and
bounded search priorities. The present dossier replay uses LegalMath’s source and
search adapters; it does not invoke those adjacent repositories. Tree-of-Thoughts and
Language Agent Tree Search motivate breadth and environment-feedback operations
(Yao et al., 2023; Zhou et al., 2024). None of these components supplies an oracle for
an unseen legal meaning. Codex can serve as a bounded candidate or review-question
generator, provided its output is treated as untrusted typed evidence and is subjected
to the same source, argument and proof gates.
