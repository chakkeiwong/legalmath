5 continued. Where Stipula belongs
Stipula describes contracts through parties, resources, actions and state changes. It is
relevant when consent can be granted and withdrawn. The published translation stud-
ied in Chapter 4 constructs a Java verification model with specifications in the Java Mod-
eling Language (JML). KeY is a verifier that reasons about the Java model and those
specifications.
