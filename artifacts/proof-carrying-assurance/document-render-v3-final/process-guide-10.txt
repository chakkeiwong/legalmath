7. Deliver a reviewable executable control
The result is a target program that another person can inspect, run and question. A Java
archive (JAR) or a declared Catala package contains the compiled code. The associated
review record identifies the sources, proposed meanings, facts, test results and unre-
solved questions. A separate host program exercises the callable control and preserves
the target identity.

8. Approve and supervise bank use
The institution decides which interpretation and exact program version it will authorize.
Its own identities, fact owners and transaction systems must preserve that decision. The
local source monitor and bounded scheduler can revisit affected controls; actual bank

Measuring whether the method helps
Empirical evaluation runs alongside development. The implemented comparison of-
fers a single reader, isolated readers, tree search and source assurance under declared
resource limits. Independent reference outcomes and unfamiliar source families are
needed to estimate interpretation quality; a separate workflow study measures people’s
review effort.
