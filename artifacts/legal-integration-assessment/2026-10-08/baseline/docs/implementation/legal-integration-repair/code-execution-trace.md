The original 420-pair full trial still did not complete. The original scoped
allowance was four actions; the minimum at batch size twelve is seventy. No
software or retrieval repair turns that budget into a feasible complete trial.
The two-pair live diagnostic is deliberately identified as a diagnostic and
never replaces the full matrix.

The first repaired combined trial exposed the distinction between syntactic
question identity and semantic scope: a response copied the narrow question's
hash but reasoned about the broad question. Its inconsistent relevance and
correspondence labels triggered rejection. Typed query routing and an explicit
question contract address that ambiguity; a hash alone cannot establish that a
model reasoned about the right question. Any stronger evaluation still needs
source-supported adjudication and independent target examples.

The old G0 product snapshot, current dirty-source baseline, preceding provider
reservations, failed calls and all original gap/reading identities remain
retained. `run_legal_integration_repair.py verify` distinguishes historical
evidence preservation from a current-method check.
