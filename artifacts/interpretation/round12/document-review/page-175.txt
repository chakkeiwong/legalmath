Consider next an amendment to the provision defining the relevant distributor. The
wording of the gift paragraph might be unchanged, yet its applicable actors could differ.
The investigation must connect the proposed rule to the edition of that definition and
the relevant date. A changed dependency invalidates the affected conclusion and its
supporting execution checks. Historical replay requires both the rule applicable to the
conduct and the evidence available at the historical cutoff. A later publication cannot
silently become evidence that was available earlier. Where the authority or temporal
relationship is disputed, the program reports that dispute instead of inventing a priority
rule.
Once a factual model and executable interpretation are explicit, the execution checks
become precise. Python, generated Java and a separately compiled Catala calculation
can be run on the same cases. An independent solver can seek an input that makes two
formal proposals disagree. A discovered input is then executed in the actual binaries,
including their explanations and evidence references. If a compiler mutation changes
an inclusive threshold to a strict threshold, the boundary case must detect the change.
If two routes share the same input validation or date handling, those shared operations
still need their own challenges. Multiple compilation paths do not make every layer
independent.
The distinction between these checks and a proof matters. A proof for a specified lan-
guage fragment would state that every valid input receives the result prescribed by its
formal semantics, under explicit runtime assumptions. Finite conformance cases are
evidence for that proposition, not its universal derivation. A theorem about a mathe-
matical evaluator requires an additional connection to the emitted Java before it estab-
lishes a property of that Java. Neither proposition, even when proved, establishes that
a chosen English interpretation included every legally relevant distinction.
A useful demonstration must therefore contain both successful decisions and unre-
solved cases. The clear cases establish that the system can produce a working Java
package and apply its stated conditions. Deliberate omissions, competing factual mod-
els and ambiguous authorities establish whether the investigation exposes the situa-
tions in which its answer needs more evidence. A system that refers every case to a
reviewer has demonstrated caution but has not demonstrated the intended reduction
in manual interpretation work.
Reference cases must be prepared with the same distinction in mind. An oﬀicial ex-
ample can provide direct evidence about the example it addresses. A constructed case
tests an explicitly stated interpretation. A case and rule written by the same agent may
repeat the same mistake. Their agreement remains useful for checking execution, while
independent source assessment is needed for a stronger interpretation claim. The eval-
uation preserves these different origins rather than combining them into one accuracy
percentage. Related scenarios from one circular also remain related observations; thou-
