  word hyphenation; the ensemble title uses a deliberate line break. No font or
  margin enlargement was used after the initial 12-point typography choice.
- Long inline paths and endpoint names overflowed narrow columns. Endpoint methods
  and paths are separated, paths wrap, and table widths fit the text block.
- A vertical assurance figure's prose said “left to right.” It now says “from one
  stage to the next.” The rendered figure and surrounding explanation agree.
- The initial controller loop tested only material issues. It now reconciles every
  unresolved discrepancy; unknown materiality blocks, and cosmetic closure needs
  a reason. Final integrity/cancellation/deadline guards also run with an empty loop.
- Per-action timeout could have extended the absolute run deadline if interpreted
  naively. The text now requires the earlier limit and distinguishes monotonic
  elapsed timing from durable UTC identity.
- “Choose next action” lacked a baseline algorithm. A deterministic lexicographic
  scheduler, family-slot rule, tie-breaks and equal-weight question baseline are
  now specified and labelled unvalidated policy choices.
- A post-report review schema could not represent an in-run adjudication without
  a dependency cycle. Separate `issue-decision` and `review-decision` records now
  define the two moments; the manuscript explains their direction.
- Bare evidence identifiers were insufficient for a meaningful closure check.
  Typed evidence records and negative checks now reject unvalidated closure and
  an equivalence claim supported only by a repair narrative.
- The semantic-uncertainty paper/code comparison now cites the pinned source and
  separately retained model-label configuration. Neutral predictions are admitted

## Mathematics and evidence

The Boolean-fragment preservation proposition is a local structural-induction
argument conditional on identical lookup and primitive tables. It is not a proof
of the current Java runtime. The quantifier examples are explicitly synthetic.
The common-error and variance formulas state their probabilistic assumptions.
The termination argument requires finite local processing, enforced timeouts and
durable accounting. The release formula is a proposed invariant, not an existing
proof of the new service. The zero-error bound assumes independent binomial trials.
Conformal coverage is marginal under a fixed score and exchangeable examples;
missing generated interpretations and distribution shift are not covered.

`check_monograph.py` checks numerical illustrations and every dual-indicator
Boolean combination, not the entire mathematical or legal argument. The separate
contract check validates a synthetic blocked dossier, sixteen invalid mutations,
an eight-state abstract budget model and the complete 16-row release predicate.
It does not simulate real concurrency, remote execution or authenticated review.

The 119 accepted runtime input identities match the retained acceptance record,
including its already documented browser-harness repair. No application code or
accepted test result was changed. The full 154-test application suite was not
rerun for this document-only task, and is not presented as newly executed evidence.
