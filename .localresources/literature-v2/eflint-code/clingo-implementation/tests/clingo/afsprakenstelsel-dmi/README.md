# Afsprakenstelsel DMI

This folder contains eFLINT that represents the Afsprakenstelsel of the [DMI Ecosystem](https://dmi-ecosysteem.nl), a consortium that use this body of norms to govern what its participants are allowed to do in the data market. It represents a larger and more realistic use-case than the other tests.

The document upon which these norms are based are [included in this repository](./Bijlage%20beleidsregels%20deelvoertuigen%20DMI%20Afsprakenstelsel.pdf). They are taken from <https://api1.ibabs.eu/publicdownload.aspx?site=zwolle&id=101032039>.

Note that the project is based in the Netherlands, and as such, both the norms and the translated eFLINT are in Dutch.

**This code is taken and adapted from <https://gitlab.com/eflint/formalisations/dmi-afsprakenstelsel>.**
